    • 양산품 동일도 ≥80% — market 동일도 50% — OK
    • 사용자 제작 역량 위반 — 차량 ECU 미사용, 외부 부착 박스/카시트 매트/도어 핸들 LED 모두 자체 동작 — OK

    4축 채점¶

    ① 실현 가능성 (19/25)¶

    • 근거: 4개월 마일스톤(M1 케이싱+캘리브레이션 / M2 TTC+BLE 메시 / M3 통합+전력 / M4 시연)이 구체적이고, 각 단계 산출물이 데모 가능 형태로 정의됨. 양산 경로는 "애프터마켓 외부 부착"으로 명확.
    • 인용: idea.md L36~41 "M1~M4 마일스톤", market.md L48 "양산 OEM SEA 옵션 가격(약 50~100만 원) 대비 가성비 포지셔닝"
    • 감점 사유: ① 외부 박스의 IP65/도난/8000mAh 배터리 30분 저전력 유지가 idea 단계에서 PoC 데이터로 입증 안 됨. ② BLE 메시 4노드(박스↔핸들 LED↔카시트 매트↔앱) 전력·지연 예산 미제시. ③ plan_designer 산출물 부재로 BOM 합계 검증 불가.

    ② 독창성 (20/25)¶

    • 근거: market 양산품 동일도 50%로 중간이지만, "OEM SEA의 애프터마켓 외부화 + 마이크로모빌리티(전동킥보드/자전거) AI 분류 + 카시트 점유 BLE 연계 + 도어별 차등 LED 알림"이라는 4중 결합은 OEM 양산·애프터마켓 모두에서 미발견.
    • 인용: market.md L24 "모든 OEM 양산품은 ① 차량 내장(애프터마켓 외부 부착 X), ② 마이크로모빌리티 분류 명시 X, ③ 카시트 점유 연계 활성화 X" / market.md L31 "통합 제품은 미발견"
    • 감점 사유: 핵심 메커니즘(후방 레이더+카메라 객체 분류)은 OEM SEA와 컨셉 중첩. 차별이 "외부화 + 분류 정밀화 + 연계"의 누적이지 단일 새 메커니즘은 아님 → 차별 한 줄 강도가 약간 분산.

    ③ 기술 적합성 (22/25)¶

    • 근거: 본인의 자율주행 객체 분류·TTC·센서 퓨전 코드 자산 그대로 재사용. mmWave 레이더+비전 융합은 ADAS 회사 기술 자산과 직접 시너지. 4대 테마(차량 혁신 + 새로운 개념) 정합성 강함.
    • 인용: idea.md L33 "본인의 자율주행 객체 분류·TTC·센서 퓨전 코드 자산 그대로 재사용 + 배우자의 어린이 외상·하차 행동 패턴 임상 관점"
    • 감점 사유: 배우자(간호사) 강점 활용은 "알림 강도/timing 설계" 수준에 머물러 #3·#4 대비 임상 contribution 비중이 낮음.

    ④ 고객 지향성 (17/25)¶

    • 근거: 페르소나 페인 명확("카시트 두 아이 한 명씩 내릴 때 다른 아이 사각"). 한국 시장 증거 강함(개문사고 과실, 전동킥보드 급증, 문콕 키워드).
    • 인용: market.md L34~38 "택시 개문사고 과실비율 / 나무위키 문콕 / 한국일보 전동킥보드 / easylaw 차 문 연 쪽 과실" / market.md L38 "페인포인트 강도 강. 마이크로모빌리티 급증 + 부모 시야 사각 + 과실 책임 차량 측 집중"
    • 감점 사유: 시장 니즈 강도 70%로 "강"이지만 #3(80%)/#4(75%)보다 낮음. "어린이 하차 사고 예방"이 부모의 일상적 구매 트리거인지, 사고 후에야 절감하는 카테고리인지 검증 부족(market.md 인용된 부모 페인은 "법률·과실" 측면이 더 강함, 일상 페인 직격 인용 부재).

    가산점¶

    • 수상 DNA 2개 이상 매핑 (+2) — DNA②(기존 기술의 영리한 재해석: SEA 외부화) + ③(사회적/포용적 가치) + ④(명확한 단일 페인포인트) 3개 명시
    • HW 4개 이상 + BOM 한도 내 (+2) — HW 4종(외부 박스 ×2, 도어 핸들 LED ×4, 카시트 매트 ×2, Jetson 중앙 처리). BOM 합계는 plan_designer 단계에서 정밀 검증 필요지만 부품 단가 추정상 한도 내
    • 시장 니즈 ≥70% (보더라인) — market 70% "강" 정확히 컷오프, 보너스 부여 (+2)
    • 자율주행+의료 모두 살림 — 자율주행 강하나 의료(간호사) 강점은 "알림 timing 설계"에 그쳐 약함 → 미부여
    • 사회적 가치 명시 — DNA③ + 어린이 교통 안전 명시되지만 ②와 일부 중첩, 단독 항목 명시는 약함 → 미부여
    • 합계: +6

    가장 약한 축 (critic 가이드)¶

    • ④ 고객 지향성 (17/25) — 가장 약한 근거: "페인이 법률·과실 중심이고 일상 구매 트리거 약함"
    • critic 이 공격할 포인트:
    • 외부 부착 박스의 미관·도난·내후성 — 부모가 일상에서 차에 매번 부착·해제하는 UX 마찰. 자석 마운트로 빠지면 도난, 두면 미관 훼손. idea L42 자가 약점에서도 인정.
    • OEM SEA가 이미 있다 + Hyundai/Kia 신차에 표준화 추세 — "왜 외부 박스인가"의 답이 "구형/외산/저가 차량"인데 그 시장이 페스티벌 양산 경로(현대차·기아 OEM 동봉)와 정합성 모순. 사내 양산 경로가 자기 OEM 카니발리제이션 우려.
    • 마이크로모빌리티 분류 정확도 — YOLOv8 fine-tuning으로 자전거/전동킥보드 5분류한다는데 한국 도심 주차장 야간/우중 시나리오 데이터 확보 계획이 idea 단계에 없음.

    critic이 집중할 약점 (plan 기준 갱신)¶

    1차 약점 3개 중 plan에서 정면 방어된 항목과 여전히 남은 항목: - ✅ 공격 #1 외부 부착 UX 마찰 — 이중 운용("주차 시 분리 / 도어 핸들 LED 영구") + 도난 와이어 + IP65 + 솔라셀 + 양산 시 색상 매칭으로 방어 강함 (plan L83, L149). - ✅ 공격 #2 OEM SEA 카니발리제이션 — "1단계 SEA 0대 시장 + 2단계 SEA Plus(마이크로모빌리티 분류 추가)"로 방어 강함 (plan L138, L151). - ⚠️ 공격 #3 마이크로모빌리티 분류 정확도 — 한국 도심 야간/우중 자체 영상 30분 + BDD100K 보강. 30분이 충분한지 critic 재공격 가능. plan L86이 "mAP 0.7 미달 시 자전거+그 외 2분류로 단순화"로 fallback 명시했으나 차별축이 약화됨.
