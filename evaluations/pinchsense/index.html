    4축 채점¶

    ① 실현 가능성 (16/25)¶

    • 근거: 4개월 마일스톤(M1 PCB·센서 캘리브레이션 / M2 임상 룰 + IMU 보정 / M3 ToF + BLE 허브 / M4 카시트 임베드 + 외투 시나리오) 구체적. 양산 경로(다이치·페도라 카시트 OEM 협업 / 신차 번들) 명시.
    • 인용: idea.md L133~138 마일스톤
    • 감점 사유: ① 5점식 하네스 직물 속에 슬림 모듈 임베드가 메이커 환경에서 시연 수준만 가능 (idea L139 자가 인정). ② 어깨 끈 전자부품의 안전성·세탁성·인증(KC/CCC/FMVSS)이 4개월 안에 입증 불가 (market L58). ③ 정전식 압력 + FSR + 변형 게이지 + IMU 다축 퓨전의 캘리브레이션이 영유아 단계별로 임상 검증 필요한데 4개월에 임상 데이터 확보 어려움. ④ 4개 후보 중 idea L133 자가 평가에서도 "#1~#3 대비 도전적"으로 인정.

    ② 독창성 (22/25)¶

    • 근거: market 동일도 35%. 5점식 하네스 어깨 끈 임베드 실시간 LED 코칭 + 체스트 클립 ToF 위치 측정 모듈은 양산·크라우드펀딩·특허 모두 미발견. 기존 양산은 모두 차량 시트벨트(카시트 하네스 X) 또는 점유·미체결 알림에 한정. "끈을 당기다 LED 녹색이 되면 멈춤"이라는 UX는 매뉴얼·앱 불필요 직관적 인터랙션으로 독보적.
    • 인용: market.md L13 "5점식 하네스 어깨 끈에 임베드된 실시간 장력·위치 LED 코칭은 미발견" / market.md L31 "양산은 모두 차량 시트벨트, 점유·미체결, 충돌 사전 인장. PinchSense의 어깨 끈 자체 LED + 실시간 장력 적정성 색상 코칭은 양산·특허 모두 미발견" / market.md L41 "양산·크라우드펀딩 모두 미발견"
    • 감점 사유: 메커니즘은 새롭지만 "장력 측정 + LED" 콤포넌트 자체는 산업용 비전(Cognex)·시트벨트 텐션 센서(Autoliv) 기존 도메인 재조합. 25/25는 부여 안 함.

    ③ 기술 적합성 (20/25)¶

    • 근거: 본인의 다축 센서 퓨전(IMU/압력/장력 동시 처리) + 임베디드 SW + 알고리즘 캘리브레이션 + 배우자(간호사) 영유아 흉곽 압박 안전 한계·체스트 클립 임상 가이드. 두 강점 모두 살아남. 테마4(완전히 새로운 개념) 정합성 강함 — 배치1·2 전체에서 테마4 가장 강한 후보.
    • 인용: idea.md L130 "본인의 다축 센서 퓨전 + 임베디드 SW + 캘리브레이션 + 배우자의 영유아 흉곽 압박 안전 한계·임상 가이드"
    • 감점 사유: ADAS·자율주행 코어 자산(비전·LiDAR·객체 분류)과의 직접 시너지는 #1·#2 대비 약함. 임베디드 센서 퓨전은 자율주행 자산이긴 하나 "ADAS 시너지" 어필력은 #1보다 낮음.

    ④ 고객 지향성 (21/25)¶

    • 근거: 페르소나 페인 매우 강함("두 아이를 한 명씩 채우면서 다른 아이가 떼를 쓰면 대충 채움" + "두꺼운 외투 슬립스루"). 한국 겨울 시즌성 + 정부 캠페인 + econmingle 매체 페인 직격 인용. market 시장 니즈 강도 75% "강". 사회적 가치(영유아 안전) 명확.
    • 인용: market.md L11 "시장 니즈 강도 75% (강)" / market.md L43~49 한국 시장 증거 5건 / market.md L49 "두꺼운 외투 + 헐거운 하네스 = 슬립스루 사고 + 자발 가이드 다수 + 정부 기관 캠페인 + 페르소나 페인 강력 일치 + 겨울 시즌성"
    • 감점 사유: 부모가 끈 LED를 보는 행동이 "한 번 정착되면 자동"이지만 첫 도입 마찰(매번 충전·페어링) 존재. 아이가 자라며 어깨 슬롯 위치 바뀔 때마다 모듈 재배치 UX 마찰.

    가산점¶

    • 수상 DNA 2개 이상 매핑 (+2) — DNA①(직관적 인터랙션: 색만 보면 됨) + ③(사회적 가치) + ④(단일 페인포인트) 3개
    • HW 4개 이상 + BOM 한도 내 (+2) — HW 4종(어깨 모듈 ×2, 체스트 클립 모듈, BLE 허브, 카시트 목업)
    • 시장 니즈 ≥70% (+2) — market 75%
    • 자율주행+의료 모두 살림 (+2) — 다축 센서 퓨전(본인) + 영유아 흉곽 압박 임상(배우자) — "두 강점 모두 살아남" (idea L130)
    • 사회적 가치 명시 — DNA③에 포함되나 단독 명시 강함. 부여 (+2)
    • 합계: +10 → 8 조정: 사회적 가치는 DNA③에 통합되어 단독 명시는 약함. 보수적으로 미부여 → +8

    가장 약한 축 (critic 가이드)¶

    • ① 실현 가능성 (16/25) — 가장 약한 근거: "5점식 하네스 직물 속에 슬림 모듈 임베드가 메이커 환경에서 시연 수준만 가능 (자가 인정)"
    • critic 이 공격할 포인트:
    • 인증·세탁성·안전 — 어깨 끈 전자부품은 KC/CCC/FMVSS 인증 없이는 양산 경로 사실상 봉쇄. "데모 시연 + OEM 양산 협업 분리"는 페스티벌 본선 수상 후 양산 단계에서 critic이 "OEM이 받을 인센티브가 무엇이냐" 직격 가능.
    • 임상 데이터 확보 — 영유아 단계별 적정 장력 임상 룰을 4개월 안에 검증할 마네킹·시뮬레이션·실측 데이터가 idea 단계에 없음. 배우자 임상 강점이 강하지만 "개인 간호사의 가이드"가 KC 인증 임상 룰이 되려면 별도 임상 시험 필요.
    • 사용자 마찰 — 카시트 1대당 어깨 모듈 ×2 + 체스트 클립 모듈 + BLE 허브 = 4개 임베디드 부품을 부모가 매번 충전·페어링·재배치(아이 성장 시). 두 아이 = 8개. critic은 "결국 부모는 안 쓴다" 공격.
    • 양산 동봉 시 BOM — 카시트 OEM 동봉 시 가격 인상 폭이 부모 구매 트리거를 상회할 위험. "$50 카시트 + $80 PinchSense"가 시장에서 받아들여질지 검증 필요.

    critic이 집중할 약점 (plan 기준 갱신)¶

    1차 약점 4개 중 plan에서 정면 방어된 항목과 여전히 남은 항목: - ✅ 공격 #1 인증·세탁성 — 1단계 슬리브(본체 무가공) → KC 영향 0 + 의료등급 실리콘 IPX7 포팅 + Pogo pin 자석 분리 충전으로 방어 강함 (plan L106, L161). - ⚠️ 공격 #2 임상 데이터 — F1 ≥0.85 물리 신호 분리로 우회. critic은 여전히 "물리 신호 분리 ≠ 임상 안전성 보장"으로 재공격 가능. plan §7 데이터 2가 "5쪽 임상 가이드 + KC 임상 시험은 사후"로 정직하게 인정 (plan L146). - ✅ 공격 #3 사용자 마찰 8모듈 — 자석 4채널 충전 도크 + 자동 페어링 + 30일+ 배터리로 방어 강함 (plan L108, L161). - ⚠️ 공격 #4 양산 BOM 가격 — 1단계 슬리브 가격 8~12만원/세트 시뮬 (plan L167). critic은 "다이치 카시트 25만원에 +50% 추가가 부모 구매 트리거 넘는가" 재공격 가능. OEM 인센티브 답은 plan §8에 명시되었으나 정량 데이터(OEM 미팅 결과) 부재 — plan §7 데이터 3에 "이메일 시도 5건" 정도.

    2차 critic 집중 약점: 1. 임상 안전성의 정량 입증 한계 — F1 0.85가 안전성 자체를 의미하지 않음. plan에서도 "KC 임상 시험은 사후"로 정직하게 분리. 본선 발표에서 "물리 신호 분리 입증 → 임상 시험 단계 → 양산"의 3단계 로드맵을 명확히 발표해야 critic이 인정. 2. W5~W8 슬리브 봉제 비전문 영역 — 본인이 봉제 비전문이라 직물 슬림 PCB 임베드 패키징이 가장 큰 일정 리스크. 1주 슬립 시 4모듈 통합 컷 → 차별축 일부 약화. 3. 양산 동봉 시 가격 점프 — OEM 미팅 정량 결과 부재. critic은 "OEM 인센티브 1쪽" 자체를 "추정"으로 공격 가능.
