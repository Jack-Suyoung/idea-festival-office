    탈락 트리거 검사¶

    • 양산품 동일도 ≥80% — market 동일도 70% (Mercedes Pre-Safe Child Seat 90%, Ellie Baby Car Monitor 80%, Magna ICS-21 75%) — 보더라인 OK (단일 평균 70%로 컷 미달, 그러나 Ellie 단일 80% + Mercedes 90%로 사실상 위험 신호)
    • 사용자 제작 역량 위반 — HVAC 미연동, 자체 디스플레이/손목 밴드/외부 LED만 — OK
    • 4대 테마 미적합 — 주 테마1(차량 혁신)/보조 테마3(사업 연관 서비스) — OK
    • 순수 SW — HW 5종(카메라 모듈, Jetson 보드, 클립 디스플레이, 진동 손목 밴드, 외부 LED 패널) — OK → 트리거 발동: 없음 (단, 양산품 동일도가 보더라인 위험 — REVISE 사유의 핵심)

    4축 채점¶

    ① 실현 가능성 (18/25)¶

    • 근거: 4개월 마일스톤(M1 카메라+Jetson 통합 / M2 마네킹+호흡 시뮬레이터 / M3 디스플레이+밴드+LED 통합 / M4 차량 시연)이 구체적. 영유아 마네킹+호흡 시뮬레이터로 PoC 데이터 입증 경로 명확.
    • 인용: idea.md L70~74 마일스톤
    • 감점 사유: ① rPPG의 영유아 신뢰도(피부톤·움직임 노이즈) 입증이 4개월 안에 임상 수준으로 가능한지 회의적 — idea L75에서도 "임상 의료기기 수준이 아닌 보조 알림 포지셔닝 필수"로 인정. ② 5개 HW 모듈 통합 + BLE 메시는 #1 대비 통합 복잡도 높음. ③ 양산 경로가 "OEM 미장착 차량 + 임상 보강"(market L49 권고)으로 좁아져 사내 양산 경로 약함.

    ② 독창성 (12/25)¶

    • 근거: market 동일도 70%로 4개 후보 중 최고. Ellie Baby Car Monitor($79)가 핵심 가치 90% 이상 커버 — 카시트 ROI 비전 AI + 호흡 + 라이브 파형 + 룸미러 자리 디스플레이가 이미 양산. Mercedes Pre-Safe Child Seat Concept 90% 동일.
    • 인용: market.md L13 "차별축이 약하므로 좁히지 않으면 DROP 위험" / market.md L28 "Ellie ... 동일도 80%" / market.md L35 "Ellie가 LullaMirror의 핵심 가치 90% 이상 커버"
    • 감점 사유: 차별 한 줄("운전석 후방 미니 디스플레이에 한 줄 시각화")이 Ellie의 5인치 LCD + 라이브 호흡 파형과 기능적 동치. "임상 룰 트리거 + 외부 LED + 손목 밴드" 3박자도 각각은 차별이지만 묶었을 때 critic이 "Ellie 사면 끝나는 거 아니냐" 직격 가능(market L50).

    ③ 기술 적합성 (18/25)¶

    • 근거: rPPG, MMPose 키포인트, 온디바이스 비전 추론 모두 본인 자율주행 비전 자산과 시너지. 배우자(간호사) 임상 룰 기반 트리거가 본 후보에서 강하게 살아남.
    • 인용: idea.md L66 "본인의 비전 AI 파이프라인 × 배우자의 영유아 호흡·체온 정상범위 임상 기준"
    • 감점 사유: 자율주행 비전과의 시너지가 #1(객체 분류·TTC) 대비 간접적. rPPG는 의료기기 도메인이라 회사 R&D 자산(ADAS·AVM)과는 거리가 있음.

    ④ 고객 지향성 (14/25)¶

    • 근거: 페르소나 페인 명확("두 아이 후석 잠들었을 때 호흡/자세 직접 확인 불가"). 시동 OFF 후 후석 방치 사고 예방은 사회적 가치 강함.
    • 인용: idea.md L51 "두 아이 뒷좌석 잠들었을 때 운전 중 호흡/자세 직접 확인 불가" / market.md L41 "후석 어린이 모니터 카메라/거울 자체는 한국 부모 사이에 일반화된 카테고리"
    • 감점 사유: market.md L41 "한국 부모는 이미 베이비 카메라 일반화 + 호흡·자세 + 외부 LED 결합 가치를 새 페인으로 인지하는지 검증 안 됨". 시장 니즈 강도 60% "중"으로 4개 후보 중 최저. 페인이 "있는 것을 더 좋게"이지 "없어서 불편"이 아님.

    가산점¶

    • 수상 DNA 2개 이상 매핑 (+2) — DNA①(직관적 인터랙션) + ③(사회적/포용적 가치) + ④(단일 페인포인트) 3개 명시
    • HW 4개 이상 + BOM 한도 내 (+2) — HW 5종 (카메라 모듈, Jetson, 클립 디스플레이, 손목 밴드, 외부 LED 패널)
    • 시장 니즈 ≥70% (60%) — 미부여
    • 자율주행+의료 모두 살림 — 의료(간호사 임상 룰)은 강하나 자율주행은 비전 일반(rPPG/MMPose)이라 핵심 자산(ADAS) 직접성 약함 → 미부여
    • 사회적 가치 명시 — DNA③에 포함되지만 단독 명시 약함 → 미부여
    • 합계: +4

    가장 약한 축 (critic 가이드)¶

    • ② 독창성 (12/25) — 가장 약한 근거: "Ellie Baby Car Monitor $79가 핵심 가치 90% 커버"
    • critic 이 공격할 포인트:
    • Ellie와의 비교 — $79 양산품이 동일 폼팩터(룸미러 자리 디스플레이) + 라이브 호흡 파형 + 듀얼 카메라 + 야간 시야 + 84% 부모 만족을 이미 제공. "차별이 임상 룰 트리거"라면 그것 하나로 좁히고 디스플레이/외부 LED/손목 밴드 모두 빼야 함.
    • Mercedes Pre-Safe Child Seat 90% 동일 — 메르세데스가 컨셉 단계지만 양산 OEM 진입 시 본 후보의 "차량용" 포지션이 무력화. 양산 경로가 "OEM 미장착 차량"으로 좁아지는 것 자체가 페스티벌 사내 양산 경로와 모순.
    • rPPG 영유아 신뢰도 — 임상 의료기기 수준 아닌 "보조 알림"이라면, "보조 알림"의 가치를 부모가 $200+ 추가로 살 만큼 인지하는지 입증 부족. 이미 Ellie $79를 사면 동일 알림.
    • 5개 HW 모듈 통합 vs 단일 폼팩터 — Ellie는 카메라+디스플레이 1개로 끝. 본 후보는 5개 BLE 메시 통합으로 사용자 셋업 복잡도 ↑. 부모가 일상에서 5개를 켜고/충전하고/페어링할까?

    환류 (REVISE 시)¶

    • → idea_generator: 폼팩터를 1~2개로 좁힐 것. 선택지 A = 임상 응급 패턴 검출(구토·기도폐쇄·발작 의심) 단일 모듈로 좁혀 의료기기 인접 포지션 → "보조 알림" 벗어나 "응급 트리거" 가치 명확. 선택지 B = 차량용 폼팩터를 떠나 가정용+이동(유모차/카시트 겸용) 매트형 1개로 좁혀 Ellie와 카테고리 분리. market.md L52~54의 환류 항목 그대로 적용.
    • → plan_designer: REVISE 후 idea 재정의 받은 다음 진행. 현 형태로 plan 진행은 비효율 (양산품 동일도 70% + 차별 한 줄 약함이 plan 단계에서 해결 불가).
