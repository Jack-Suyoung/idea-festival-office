    4축 채점¶

    ① 실현 가능성 (22/25)¶

    • 근거: 4개월 마일스톤(M1 박스 통합 PoC / M2 카시트 5종 OCR + 룰 작성 / M3 로드셀 캘리브레이션 + DB / M4 30개 시나리오 시연)이 가장 구체적이고 검증 가능. 양산 경로 3가지 명시(현대차·기아 신차 동봉 / 카시트 OEM 협업 / 보건복지부 영유아 안전 사업).
    • 인용: idea.md L102~107 마일스톤 / idea.md L90 양산 경로 / market.md L55~56 "현대차·기아 패밀리 SUV 신차 구매 시 동봉 액세서리 → 페르소나 직접 타겟"
    • 감점 사유: ① 카시트 모델 DB 구축 비용(라벨 인식 데이터 + 설치 가이드 정리)이 4개월 안에 5종으로 한정해도 부담 — idea L108 자가 인정. ② 만료일/리콜 DB는 OEM 협업 없이 한계.

    ② 독창성 (23/25)¶

    • 근거: market 동일도 30%로 4개 후보 중 최저. 부모용 휴대형 자가 점검 비전 AI 도구는 양산·애프터마켓 모두 미발견. 기존 솔루션(Britax ClickTight·Cybex SensorSafe·Nuna Virtual)은 모두 자체 카시트 한정 또는 인적 서비스. "휴대형 + 다 모델 + ToF 정량 + 로드셀 + 라벨 OCR + 임상 룰 + 5초 UX"의 7중 결합은 미발견.
    • 인용: market.md L13 "양산 사례 미발견. 차별축 가장 명확" / market.md L25 "부모가 들고 다니며 다 모델·정량·자동 진단하는 휴대형 도구는 미발견" / market.md L35 "부모용 휴대형 자가 점검 비전 AI 도구는 미발견. NHTSA 46% 통계가 시장 통증의 정량 근거"
    • 감점 사유: 카시트 모델 DB는 누군가 만들면 빠르게 추격 가능(클라우드 + OCR이 핵심 진입장벽 낮음). 25/25는 명백한 근거 없으면 부여 안 함 원칙.

    ③ 기술 적합성 (21/25)¶

    • 근거: 본인의 비전 OCR·키포인트·센서 캘리브레이션·각도 추정 코드 자산 + 배우자(간호사)의 영유아 카시트 임상 가이드라인·CPST 매뉴얼·만료일 관리. 두 강점이 후보 중 가장 직접적으로 결합 — 배우자가 진단 알고리즘 임상 룰베이스를 직접 작성 가능. 4대 테마 정합성(사업 연관 서비스 + 차량 혁신).
    • 인용: idea.md L99 "두 강점이 후보 중 가장 직접적으로 결합 — 배우자가 진단 알고리즘의 임상 룰베이스를 직접 작성 가능"
    • 감점 사유: 자율주행 ADAS 자산(객체 분류·TTC·센서 퓨전)과의 시너지는 #1보다 약함 — 본인 강점이 비전 일반(OCR/캘리브레이션)으로 흘러감. ToF 어레이 + 로드셀 + IMU 다축 센서 퓨전은 자율주행 코어와 가장 인접한 부분.

    ④ 고객 지향성 (22/25)¶

    • 근거: 페르소나 페인 매우 명확(두 아이 + 간호사 + 카시트 부모). NHTSA 46% 통계가 정량 근거. 한국 시장 증거 다수(미주 한국일보 / 클리앙 / 보배드림 / 베이비뉴스 / 행정안전부 캠페인 / CDOT 한국어 가이드). market 시장 니즈 강도 80%로 4개 후보 중 최고. 사회적 가치(영유아 교통 안전) 명확.
    • 인용: market.md L11 "시장 니즈 강도 80% (강)" / market.md L37~44 한국 매체·정부 7건 / idea.md L83 "DNA③ 사회적/포용적 가치 + ④ 명확한 단일 페인포인트 + ⑤ 양산 경로 명시"
    • 감점 사유: "5초 자가 점검"이 부모의 일상 행동에 정착하려면 OEM 동봉 + 캠페인 필요 — 부모가 자비로 $200+ 사는 카테고리가 아닐 수 있음. 양산 경로 OEM 의존도 높음.

    가산점¶

    가장 약한 축 (critic 가이드)¶

    • ③ 기술 적합성 (21/25) — 가장 약한 근거: "자율주행 ADAS 자산과의 직접 시너지가 #1 SafeAlight Pod보다 약함"
    • critic 이 공격할 포인트:
    • "왜 휴대형 박스인가, 스마트폰 앱이면 안 되나" — 본인 idea L108에서도 자가 인정한 약점. 답은 "ToF 4×4 zone + 2축 로드셀 + IR 링이 폰에 없음 + 정량 측정이 핵심" (market.md L54). 그러나 critic은 "폰 + 외장 BLE 도구 1~2개"의 대안을 제시할 가능성.
    • 카시트 모델 DB 구축 비용·지속성 — 5종 PoC는 가능하나 한국 시장 카시트 100+ 모델로 확장 시 OCR 정확도/만료일 정보 유지가 문제. OEM 협업 없이는 한계.
    • 부모 자비 구매 의향 — $200+ 도구를 일회성 점검에 사는가, OEM 동봉이 양산 경로 핵심인데 OEM이 받아줄 인센티브는? "현대차·기아가 자기 차에 다른 OEM 카시트 점검 도구를 동봉할 이유"를 더 명확히.
    • 자율주행 SW 강점 활용 약함 — 비전 OCR/캘리브레이션은 일반 비전 영역. ADAS·자율주행 코어 자산(객체 분류·TTC·센서 퓨전)이 본 후보에서 직접 발휘되는 부분이 ToF+IMU 다축 퓨전 정도로 한정. 회사 R&D 자산 시너지 어필이 #1보다 약함.
