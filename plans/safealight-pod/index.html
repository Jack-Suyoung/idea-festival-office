    구현 계획 — SafeAlight Pod (외부 부착형 어린이 하차 안전 박스)¶

    1. 한 줄 요약¶

    • 4개월 동안 만들 것: 차량 후방 휀더 자석 부착형 외부 박스 ×2(레이더+카메라+Jetson) + 도어 핸들 LED 클립 ×4 + 카시트 압력 매트 ×2 + 부모 앱이 BLE 메시로 통합되어 자전거/킥보드 접근 시 적·황·녹 LED + 외부 부저 + 폰 알림을 트리거하는 자체 동작 시제품 1세트.
    • 핵심 데모 메시지: "당신의 차에 SEA가 없어도, 외산 차량이어도, 1분 만에 자석으로 붙이면 카시트 두 아이를 안고 내릴 때 자전거·킥보드를 부모 대신 본다."

    2. 16주 마일스톤¶

    단계 주차 주요 작업 나가는 산출물 통과 기준
    M1 W1-4 부품 발주(W1), Jetson Orin Nano 플래싱·CUDA·DeepStream 셋업, USB IR 카메라+레이더 단독 동작 검증, YOLOv8 사전학습 모델 + COCO 클래스에서 자전거/오토바이/사람 추출, 한국 도심 주차장 자전거·킥보드 영상 자체 수집(주차장 야간/우중 포함 30분 이상), fine-tuning 1차. 박스 케이싱 1차 SLA 3D 프린팅(IP65 가스켓 홈 포함) PoC 영상 #1: 책상 위에서 자전거 모형이 카메라 시야에 들어오면 LED 적색 점등 (단일 박스, BLE 미통합) YOLOv8n 자전거/킥보드/보행자 3분류 mAP@0.5 ≥ 0.70 (자체 수집 50장 검증셋)
    M2 W5-8 TTC(Time-To-Collision) 산출 알고리즘(레이더 거리·속도 + 카메라 bbox 결합), BLE 메시 4노드 통신 프로토콜(박스↔도어 핸들 LED↔카시트 매트↔폰 앱), 도어 핸들 LED 클립 ×4 PCB 조립, 카시트 압력 매트 ×2 FSR 어레이 캘리브레이션, 박스 IP65 케이싱 2차(실리콘 가스켓 본드 결합), 자석 마운트 100회 탈착 내구 테스트 통합 데모 v1: 연구실 책상에 박스 1개 거치 + 도어 핸들 LED 1개 + 카시트 매트 1개 + 폰 앱 — 압력 가하면 박스 액티브, 자전거 모형 접근하면 LED 적색 + 폰 푸시. TTC 정확도 ±0.5초(2~5m 범위), BLE 메시 end-to-end 지연 ≤ 300ms, 자석 100회 탈착 후 케이싱 손상 없음
    M3 W9-12 박스 ×2 좌·우 동시 운용(좌·우 도어 차등 알림), 시동 OFF 후 30분 저전력 액티브 모드(레이더 듀티 사이클 10%), 카시트 점유 연계 false positive 5% 이하 튜닝, 도난 방지 와이어 마운트, 솔라셀 보조 패널 옵션 부착, 차량 모형(1/10 RC카) + 카시트 마네킹 두 아이 + 자전거/킥보드 모형 시나리오 5종 셋업, 외부 부저 데시벨 측정(70dB 이하 합법성 확인) 통합 데모 v2 + 케이싱 완성: 차량 모형에 박스 ×2 자석 부착 + 좌·우 도어 핸들 LED + 카시트 매트 ×2 — 두 아이 점유 + 우측 자전거 접근 시 우측 도어 핸들만 적색, 좌측은 녹색. 시동 OFF 30분 후에도 동작. False positive 5% 이하(빈 박스/일반 보행자/지나가는 차량을 위험으로 오인 X), 시동 OFF 후 저전력 30분 유지, 부저 70dB 이하 측정 리포트
    M4 W13-16 실차 1대(본인 차량) + 카시트 마네킹 ×2 + 자전거/킥보드 실물 ×1로 야외 주차장 시연 영상 5종 촬영(주간/야간/우중/낮 그림자/대낮 역광), 사전 녹화 fallback 영상 편집, 5분 발표 슬라이드(메커니즘 도해·차별 각도·양산 경로·critic 정면 방어), 리허설 3회, 발표용 박스 외관 다듬기(헤어라인 마감), BOM·PoC 데이터 정리. 발표 영상 + 슬라이드 + 실시연 박스 1세트 5분 발표 시간 안에 들어오고, 시연 1회 라이브 + fallback 영상 둘 다 동작, critic 예상 질문 5종에 답변 카드 준비

    4. HW/SW 분담¶

    • 가용 시간: 본업 외 평일 저녁 12시간 + 주말 6시간 = 주 18시간 × 16주 = 약 288시간
    • HW 작업: 35% (약 100시간) — 박스 케이싱 SLA 3D 프린팅·IP65 가스켓 본드 결합·자석 마운트 설계·도어 핸들 LED 클립 PCB 발주/조립·카시트 매트 FSR 어레이 본드·도난 와이어/솔라셀 통합·실차 부착 지그
    • SW 작업: 45% (약 130시간) — YOLOv8 fine-tuning(자전거/킥보드/보행자 한국 도심 데이터)·TTC 알고리즘·BLE 메시 4노드 프로토콜·저전력 듀티 사이클·카시트 점유 연계 룰·부모 앱(Flutter or React Native 단일 화면)

    • 데모 준비: 20% (약 58시간) — 야외 주차장 시연 영상 5종 촬영·편집·fallback 영상·5분 슬라이드·리허설 3회

    • 4개월 가능성: 타이트하지만 가능.

    • 위험 시점: M2 W6-7의 BLE 메시 4노드 통신과 M3 W10-11의 false positive 튜닝. 본업 야근/가족 일정 충돌 시 1주 이상 슬립 가능성.
    • 축소판 fallback (위험 시 우선 축소 항목):
      1. 솔라셀 보조 패널 → 슬라이드에 도해만 (BOM #9 제외)
      2. 도어 핸들 LED 4개 → 2개(우측 전·후만)로 축소
      3. 카시트 매트 2개 → 1개로 축소(한 명 시나리오)
      4. 박스 ×2 → 박스 ×1(우측만, 한국 도심 도어 사고 우측 인도 측 다수)
    • 위 4개를 다 축소해도 핵심 데모 메시지(자전거 접근 → 도어 핸들 LED 적색 + 외부 부저)는 보존됨.

    5. 리스크 & 대응¶

    리스크 시점 영향 대응 백업
    외부 부착 박스의 도난·미관·내후성 (critic 핵심 공격) M3, 발표 상 ① 도난 방지 강철 와이어 + 휀더 내측 자석 마운트 위치(시인성↓) ② IP65 케이싱 + 실리콘 가스켓 본드 + 솔라셀 보조 ③ 양산 시 차량 색상 매칭 옵션 도해 발표 시 "주차 시 박스 분리 → 도어 핸들 LED는 영구 부착" 2단계 운용 시나리오로 미관·도난 동시 회피 한 슬라이드 명시
    OEM SEA 카니발리제이션 (현대차·기아 사내 양산 모순) 발표 상 "1단계 H-Genuine Accessory 애프터마켓 → SEA 미장착 구형/중고/외산 차량 대상" + "2단계 OEM 옵션 시 마이크로모빌리티 분류 추가 가치"로 정면 방어 한 단락 (섹션 9 참조) 사내 OEM 양산 PM 인터뷰 사전 예약(W12까지) — 양산 카니발리제이션 우려 답변 카드 직접 검증
    시동 OFF 후 박스 배터리 30분 미달 M2, M3 중 레이더 듀티 사이클 10%(0.1s on / 0.9s off) + 카메라는 레이더 트리거 시만 깨움 + Jetson은 Always-on Nano 모드(2.5W) 8000mAh → 12000mAh로 셀 증설 (예비비로 +30,000원). 또는 솔라셀 패널로 야간 외 정상 충전
    마이크로모빌리티 분류 정확도 (critic 공격 #3) M1, M2 중 한국 도심 주차장 야간/우중 자체 영상 30분 이상 + 공개 데이터셋(BDD100K, KITTI) 보강 + YOLOv8n으로 시작해 정확도 부족 시 YOLOv8s로 업그레이드 M2까지 mAP 0.7 미달 시 "분류는 자전거+그 외 2분류로 단순화", 발표 시 "범주 분리는 양산 단계에서 추가 학습"으로 명시
    합법적 외부 경고 데시벨 (도로교통법 자동차 경음기 규제) M3 중 외부 부저 70dB 이하(자동차 경음기 110dB 이하 규제 상단보다 한참 낮음) 측정 리포트 + 차량 외부 LED 스트로보를 메인 경고로 + 부저는 보조. 야간엔 LED만 발표 시 "법적 회색지대 회피를 위한 LED 우선 + 부저 보조" 정책 한 줄. 측정 데이터(소음계 사진)를 슬라이드에
    카메라 프라이버시 (외부 부착 카메라가 보행자 촬영) 발표 중 영상은 박스 내부에서만 추론, 저장 X(온디바이스). 추론 후 즉시 폐기 명시. 박스 외부에 "온디바이스 추론 / 영상 저장 안 함" 스티커 부착 GDPR/PIPA 한 슬라이드 — 추론 결과(객체 종류·거리)만 BLE 송신, 픽셀 0 송신 명시
    BLE 메시 4노드 지연·끊김 M2 중 nRF Connect SDK 또는 ESP-NOW(브로드캐스트, 메시 페어링 불필요) 우선. 거리 5m 이내 직접 통신 가정 ESP-NOW 실패 시 박스가 BLE 게이트웨이 + Wi-Fi 핫스팟으로 폰 직접 연결
    부품 수급 지연 (Acconeer XM125 2주, PCB 2주) M1 중 W1 즉시 발주, Acconeer 대신 Texas Instruments IWR1443(국내 재고 가능)을 백업 레이더 미수령 시 카메라+IMU만으로 PoC 진행, 레이더는 M2 W6에 통합
    본업·가족 일정 충돌 (1주 이상 슬립) M2~M3 중 주 18시간 가용 시간 + 16주 일정에 슬립 2주 버퍼 사전 반영. 배우자(간호사)는 본업 외 시간 자문만, 코드 0 기여 가정 M3 시작 시점에 일정 점검 — 슬립 발생 시 솔라셀·도어 핸들 LED 4→2개 축소 즉시 결정

    6. 본선 데모 시나리오 (5분)¶

    시간 화면/행동 메시지
    0:00-0:30 페인 영상: 부모가 마트 주차장에서 카시트 두 아이를 한 명씩 내리는 동안 우측에서 전동킥보드가 휙 지나가는 사전 녹화 영상(배우자가 출연 가능) "당신 차에 SEA가 없거나, 외산 차량이거나, 구형이거나. 그동안 두 아이의 도어 사각은 누가 봐주나?"
    0:30-2:00 메커니즘 슬라이드 + 박스 분해 도해(레이더+카메라+Jetson+배터리+자석 마운트) + BLE 메시 4노드 토폴로지 그림 + 시동 OFF 30분 저전력 타임라인 "차량 ECU 0의존, 자석으로 1분 부착. 카시트 매트가 '아이 탑승 중'이라고 박스에 알리면, 박스는 시동 OFF 후에도 30분 깨어 있다."
    2:00-3:30 실시연(라이브): 본인 차량 우측 휀더에 박스 자석 부착 → 카시트 마네킹 두 아이 좌·우 매트에 안착 → 시동 OFF → 발표자가 자전거 모형을 우측 후방에서 천천히 접근 → 우측 도어 핸들 LED 적색 + 외부 부저(70dB 이하 짧은 비프) + 폰 앱 "오른쪽 위험: 자전거 4m" 푸시 → 자전거가 멀어지면 LED 녹색 복귀. 좌측 도어 핸들은 내내 녹색(차등 알림 강조). "도어 핸들이 색깔로 말해준다. 위험한 도어는 손에 닿기 전에 빨갛다."
    3:30-4:00 실시연 fallback 영상(M4 W13-15 사전 녹화): 동일 시나리오 + 야간 + 우중 + 전동킥보드까지 4종 컷. 라이브 시연 실패해도 즉시 재생 "주간뿐 아니라 야간·우중에도 동일하게 동작 — 마이크로모빌리티 시대의 부모 도구."
    4:00-5:00 차별 한 줄 + critic 정면 방어 1슬라이드(외부 부착 UX + OEM 카니발리제이션) + 양산 경로 2단계(H-Genuine Accessory → OEM 옵션) + 팀 강점(자율주행 인지 스택 + 간호사 임상) + 사회적 가치(어린이 교통 안전 + 마이크로모빌리티 안전) "OEM SEA를 대체하는 게 아니라, SEA가 없는 곳에 먼저 가고, SEA가 있는 곳에 마이크로모빌리티 분류를 더한다."

    시연 실패 리스크 + fallback: - 실패 위험 부품: ① BLE 메시 (혼잡 RF 환경에서 페어링 끊김) ② 자석 마운트(휀더 도장면 미세 진동에 의한 미세 이동) ③ Jetson 외부 햇빛 노출 시 디스플레이 가독성. - fallback 영상: M4 W13-15에 동일 시나리오 4종(주간/야간/우중/킥보드)을 사전 녹화. 라이브 시연 시작 30초 이내 BLE 페어링 미감지 시 즉시 영상 모드로 전환(발표자가 노트북 키 1번으로 트리거). - 이중 백업: 박스 ↔ 폰 직접 BLE 연결을 보조 채널로 항상 유지(메시 끊겨도 폰 알림은 도달).

    7. PoC 데이터 (예선 단계 산출 목표)¶

    본선 진출 전 서류·예선 3개월 동안 만들어야 할 정량 데이터(실현 가능성 점수 근거):

    • 데이터 1 — 객체 분류 정확도: 한국 도심 주차장 야간/우중 자체 수집 영상 30분 + 공개 데이터셋 보강으로 YOLOv8n 자전거/전동킥보드/보행자 3분류 mAP@0.5 ≥ 0.70 검증 리포트 (slide 1장).
    • 데이터 2 — 자석 마운트 내구성: 휀더 도장면 100회 탈착 + 80km/h 풍동 모사(또는 차량 주행 30분) 후 박스 위치 변위 ≤ 5mm.
    • 데이터 3 — 시동 OFF 저전력 가동 시간: 8000mAh 배터리 + 듀티 사이클 10% 조건에서 최소 30분 액티브 모드 유지 측정 로그(전류계 데이터).
    • 데이터 4 — 외부 부저 데시벨: 1m 거리에서 70dB 이하 측정(소음계 사진 + 도로교통법 경음기 110dB 한도 대비 비교 차트).
    • 데이터 5 — BLE 메시 지연: 박스↔도어 핸들 LED↔카시트 매트↔폰 4노드 end-to-end 지연 ≤ 300ms (1분간 1000회 측정 평균).
    • 데이터 6 — False Positive 율: 정상 보행자 + 지나가는 차량 + 빈 박스 100시나리오에서 위험 알림 오발생 ≤ 5%.

    이 6개 데이터가 "실현 가능성 19/25 → 22/25" 보강의 핵심 근거가 되며, evaluator·critic의 "PoC 데이터로 입증 안 됨" 감점 사유 직접 해소.

    8. 양산 경로 (critic "OEM SEA 카니발리제이션" 정면 방어)¶

    1단계 — 애프터마켓 (W17~6개월)¶

    • 현대차·기아 H-Genuine Accessory 채널 또는 일반 매장 (오토바이·자전거 액세서리 매장 포함).
    • 타겟 시장:
    • SEA 미장착 구형 현대차·기아 (2018년 이전, 약 600만 대 추정)
    • 외산 브랜드 (BMW·벤츠 일부 모델 SEA 옵션 미선택분 + 도요타·혼다 한국 판매 모델)
    • 카시트 사용 부모 (한국 영유아 약 80만 명 × 평균 카시트 6년 사용)
    • 가격 포지션: 박스 ×2 + 도어 핸들 LED ×4 + 카시트 매트 ×2 풀 세트 약 80만 원 (OEM SEA 옵션 트림업 차이 50~100만 원 대비 가성비).

    2단계 — OEM 옵션 / 신차 동봉 (12~24개월)¶

    • 카니발리제이션 회피 포지셔닝: "신차 SEA를 대체"가 아니라 "신차 SEA에 마이크로모빌리티 분류 + 카시트 점유 연계 + 도어별 차등 알림을 더하는 상위 옵션".
    • 현대차·기아 SEA 표준화 추세와 정합: 표준 SEA가 후방 차량만 본다면, SafeAlight Pod는 자전거·전동킥보드·보행자를 추가 분류하는 "SEA Plus" 포지션.
    • 카시트 OEM 협업: 다이치·페도라·브라이택스와 카시트 매트 동봉 번들 → 어린이 탑승 차량 한정 자동 활성화 시나리오.

    3단계 — 모빌리티 서비스 (24개월~)¶

    • 현대차·기아 카셰어링·렌터카 차량에 박스 ×2 표준 부착 → 카시트 동승 가족 단위 고객의 안전 차별화.

    9. critic 방어 포인트 (한 단락)¶

    외부 부착 UX (도난·미관·내후성): 자석 마운트는 휀더 내측에 위치하여 외부 시인성이 낮고, 강철 와이어 도난 방지 + IP65 가스켓 케이싱 + 솔라셀 보조 + "주차 시 분리 / 도어 핸들 LED는 영구 부착" 2단계 운용 시나리오로 미관·도난·전력을 동시에 회피한다. 양산 시에는 차량 색상 매칭 옵션과 휀더 통합 마운트(접착식)로 마감 품질을 OEM 수준으로 끌어올린다.

    OEM SEA 카니발리제이션: 현대차·기아 사내 양산과의 충돌은 "신차 SEA 대체"가 아니라 "SEA 미장착 구형/외산/저가 차량 retrofit + 마이크로모빌리티 분류 추가 가치" 두 축으로 회피한다. 1단계 애프터마켓은 SEA 0대 차량을 시장으로 잡고, 2단계 OEM 옵션은 표준 SEA 위에 자전거·킥보드 분류와 카시트 점유 연계를 더하는 "SEA Plus"로 포지션한다. 카니발리제이션은 발생하지 않으며 오히려 SEA 양산 라인의 옵션 매출을 늘린다.
