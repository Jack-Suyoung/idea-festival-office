    구현 계획 — PinchSense (5점식 하네스 장력·위치 실시간 LED 코칭 모듈)¶

    slug: pinchsense 작성일: 2026-05-10 작성자: plan_designer 입력 후보: reports/ideas/2026-05-10-batch2.md (#4 PinchSense) 시장 조사: reports/ideas/pinchsense-market.md (차별 각도 ①/②/③ 인용) 평가 결과: reports/evaluations/pinchsense.md (총점 87, GO. 가장 약한 축 ① 실현 가능성 16/25) 제작 역량 한계 검증: 차량 ECU 미사용 / 카시트 자체 모듈 / 외부 부착 패턴 — 위반 0건

    1. 한 줄 요약¶

    • 4개월 동안 만들 것: 카시트 1대 + 마네킹 2명 + 두꺼운 외투 슬립스루 시연이 가능한 어깨 끈 임베드 LED 코칭 모듈 1세트(좌/우 어깨 + 체스트 클립 + BLE 허브) + 두 아이용 4모듈 통합 데모
    • 핵심 데모 메시지: "끈을 당기면 LED가 빨강→노랑→초록으로 바뀐다. 부모는 초록이 될 때까지만 당기면 끝이다. 두꺼운 외투가 끼면 다시 빨강이 켜진다."

    2. 16주 마일스톤¶

    단계 주차 주요 작업 나가는 산출물 통과 기준
    M1 W1-4 부품 발주(중복 LT 대비 W1 즉시), ESP32-C3 펌웨어 부팅, FSR 압력+변형 게이지 단독 캘리브레이션, 카시트 1대 분해·하네스 폭 실측, 3D 프린팅 케이싱 1차 형상 출력, W4 게이트: 외투 두께 vs 텐션 vs 픽스 위치 PoC 알고리즘 어깨 모듈 PoC 영상 + 측정 데이터 CSV(외투 0/1/2겹 × 장력 3단계 × 9샘플) FSR+변형 게이지 합성 신호로 "헐거움/적정/과도" 3-class 정확도 ≥80%, 외투 0겹 vs 2겹 분리 가능
    M2 W5-8 IMU 각도 보정·센서 퓨전 알고리즘 작성, RGB LED 색상 맵핑(적·황·녹) 실시간 응답 ≤200ms, 어깨 모듈 1차 시제품 완성(직물 슬리브 + 슬림 PCB 임베드), BLE 허브 펌웨어, W8 게이트: 어깨 끈 임베드 모듈 1차 시제품 좌/우 1세트 + 마네킹 1명 작동 시제품 1세트(좌/우 어깨) + 1차 통합 데모 영상(연구실, 마네킹 1명) 부모가 끈을 당기는 동작에 LED가 ≤200ms 내 색 변화, 임상 룰(배우자 작성)대로 적정 텐션 범위 ±15% 정확도
    M3 W9-12 체스트 클립 ToF 모듈(VL53L1X) 통합·위치 측정, 케이싱 IPX7 방수 처리(에폭시 포팅 + 자석 분리 충전), 4모듈 동시 BLE 페어링 멀티플렉싱, 두 아이용 카시트 2대 × 모듈 4세트 통합, W12 게이트: 4세트 통합 + 세탁 5회 후 동작 통합 데모 v2 + 케이싱 + 세탁 테스트 리포트 카시트 2대에 4세트 동시 동작, IPX7 가정 세탁 5회 후 계측치 드리프트 ≤10%, 체스트 클립 위치 ±1cm 측정
    M4 W13-16 두꺼운 외투 슬립스루 시연 시나리오 셋업(겨울 패딩 마네킹), 5각도 시연 영상 촬영, 사전 녹화 fallback 영상, 5분 발표 슬라이드 + 도해, 페르소나(부모) 사용성 검증 1회, 리허설 3회 발표 영상(5분, 메인 + fallback) + 슬라이드 + 사용성 결과 1쪽 5분 발표 리허설 통과(타이밍 ±10초), 시연 1회 무사고 + fallback 영상 100% 준비

    M1~M4 공통 게이트: 매 마일스톤 종료 시 배우자(임상 자문) 1시간 리뷰 — 임상 룰 일치성·안전 한계 위반 여부 점검.

    3. BOM (부품 표)¶

    4. HW/SW 분담¶

    인시(man-hour) 산정¶

    • 본인(엔지니어): 본업 외 평일 저녁 12시간 + 주말 6시간 = 주 18시간 × 16주 ≈ 288시간
    • 배우자(간호사, 임상 자문): 본업 외 주 3시간 × 16주 ≈ 48시간 (코드 미작성, 임상 룰 작성·리뷰·안전 한계)
    • 페르소나(부모): 사용자 테스트 4회 × 1시간 = 4시간

    본인 288시간 배분¶

    영역 비중 시간 주요 작업
    HW 작업 35% ~100h 케이싱 3D 모델링·출력, PCB 시제품·납땜, 직물 슬리브 봉제, 실리콘 포팅, 자석 충전 도크, 카시트 임베드 가공
    SW 작업 45% ~130h ESP32-C3 펌웨어, FSR+변형게이지+IMU 다축 센서 퓨전, 임상 룰 알고리즘 구현(배우자 룰 → 코드), BLE 메시(4모듈 + 허브), LED 색상 맵핑, 데이터 로깅
    데모 준비 20% ~58h 시연 시나리오 설계, 5각도 영상 촬영·편집, 사전 녹화 fallback, 슬라이드 작성, 리허설 3회

    4개월 가능성: 타이트 (정성적 단언)¶

    • 가능 근거: 본인의 임베디드 + 다축 센서 퓨전 코드 자산이 직접 재사용. 부품은 모두 국내 1-2일 LT 또는 알리 7-10일.
    • 타이트 근거 — 위험 시점:
    • W5-8 (M2): 어깨 끈 임베드 패키징(슬림 PCB + 직물 슬리브 봉제)이 본인 비전문 영역. 이 시점 지연 시 W9~12 4모듈 통합이 1주 밀린다.
    • W11-12: 4모듈 BLE 멀티플렉싱 + 세탁 5회 테스트. 세탁 후 드리프트 발견 시 케이싱 재포팅 필요 → 1주 버퍼 소진.
    • 위험 발현 시 축소판 우선순위(컷 순서):
    • 두 아이용 4모듈 통합 → 1세트(어깨 ×2 + 클립 ×1)만 동작, 두 번째 카시트는 시연 영상으로 대체
    • IPX7 세탁 5회 → 1회 침수 테스트로 축소
    • 자석 충전 도크 → USB-C 직결로 대체
    • 페르소나 사용성 테스트 → 사후 의향 인터뷰로 대체
    • 절대 사수: 어깨 끈 임베드 LED 실시간 색상 코칭 1세트 + 외투 0겹 vs 2겹 슬립스루 검출 시연. 이 둘이 빠지면 차별축이 무너진다.

    5. 리스크 & 대응¶

    # 리스크 시점 영향 대응 백업 플랜
    R1 어깨 끈 임베드 시 카시트 인증(KC/CCC/FMVSS) 영향 — critic 핵심 공격 M2~M3 상 발표·계획서 전면에 "1단계: 애프터마켓 어깨 패드 슬리브(카시트 본체 무가공) → 2단계: OEM 임베드 번들" 분리 명시. 시연용 시제품은 카시트 본체 변경 없이 어깨 끈 위에 슬리브 형태 부착 — KC/FMVSS 인증 영향 0. OEM 임베드는 기술 라이선싱 사업 모델로 전환. 본 데모는 슬리브형으로 양산 인증 가능 경로 확보
    R2 세탁성 — IPX7 모듈이 가정 세탁(40°C, 표백제) 5회 후 드리프트 / 직물 슬리브 변색 M3 (W11-12) 상 의료등급 실리콘 포팅 + Pogo pin 자석 분리 충전 → 모듈 자체는 분리 후 슬리브만 세탁. 시연 영상에 "모듈 분리 → 슬리브만 세탁기 → 재장착" 30초 컷 포함 분리형 슬리브 양산 시도 실패 시, "탈착 가능한 모듈"로 컨셉 단순화. 세탁성 입증은 1회 침수+24시간 건조로 축소
    R3 카시트 1대 4모듈(두 아이 8개) 사용자 마찰 — critic 핵심 공격 M3~M4 상 (1) 자석 4채널 충전 도크로 4모듈 동시 충전 1초(부모 액션 1회). (2) BLE 허브가 자동 페어링 — 부모는 페어링 UX를 보지 않는다. (3) 배터리 수명 30일+ 목표(딥슬립 ≤30µA). (4) 발표 슬라이드에 "충전 도크 1개 = 두 아이 카시트 4모듈 = 부모 액션 1회/월" 정량 명시 8모듈 → 6모듈로 단순화(체스트 클립을 카시트당 1개에서 공용 1개로 통합). 또는 어깨 모듈만으로 핵심 가치 전달하고 클립 모듈은 옵션화
    R4 배터리 수명 — 어깨 모듈 100mAh가 LED 상시 점등 시 30분 미만 M2 중 LED는 "끈을 당기는 행동 감지(IMU 가속도 임계)" 시에만 5초 점등. 평소는 딥슬립. 측정 시뮬레이션 결과 일평균 10회 체결 × 5초 = 50초/일 → 100mAh로 30일+ 추정 150mAh로 증량 (BOM 영향 +1만원). 주차장에서 밤새 LED 켜진 채 방치 방지 자동 OFF 타이머
    R5 오탐 — FSR+변형게이지 다축 신호가 영유아 체격(8kg vs 15kg)·외투 두께(0~2겹)·하네스 마모도에 따라 임계치 변동 M1~M2 (W4 게이트) 상 임상 룰을 "절대 임계치"가 아닌 "상대적 변화 패턴(체결 직후 5초 텐션 곡선)"으로 설계. 배우자가 영유아·토들러 단계별 흉곽 압박 안전 한계 ±15% 룰 작성. 사용 전 1회 보정(빈 카시트 0점 캘리브레이션) UX 임계치 자동 학습(처음 10회 체결 데이터로 부모별·아이별 베이스라인 형성). 오탐 시에는 황색(중간)으로 안전한 쪽 표시
    R6 부품 수급 — Loadstar 변형 게이지(7-10일 LT)·실리콘 포팅(5-7일)·외투 마네킹(7-14일) 지연 M1 (W1-2) 중 W1 즉시 모든 LT 7일+ 부품 일괄 발주. 변형 게이지 대안 1종(저가 HX711 + 캔틸레버 빔)도 동시 발주 변형 게이지 도착 지연 시 FSR 단독 + IMU 보정으로 텐션 추정. 정확도 -10% 감수하고 데모 진행
    R7 가족·본업 충돌 — 본업 야근 주간 발생 시 주 18시간 확보 불가 M2~M3 중 매주 일요일 1시간 진척 점검·다음 주 plan 재조정. 본업 야근 예상 주간은 사전에 HW 발주 완료 → 펌웨어 작업으로 회피 4주마다 1주 버퍼 주차 확보. 위 "축소판 우선순위 컷 순서" 적용

    리스크 7건 모두 백업 플랜 명시 — 무효 리스크 0건.

    6. 본선 데모 시나리오 (5분 발표)¶

    시간 화면/행동 메시지
    0:00-0:30 페인 영상: 한국 부모가 겨울 패딩 입은 영유아를 카시트에 앉히고 하네스를 채우는 실제 영상(econmingle 인용 + 페르소나 가족 동의 영상). 자막: "한국 영유아 카시트 슬립스루 사고 X건/년, 정부 캠페인 운영 중" 두꺼운 외투 + 헐거운 하네스 = 슬립스루. 부모는 매번 pinch test를 못 한다.
    0:30-2:00 메커니즘 슬라이드 + 도해: ① 어깨 모듈(FSR + 변형게이지 + IMU + LED) 단면도. ② 체스트 클립 ToF 위치 측정. ③ "끈 당김 → LED 적→황→녹" 인터랙션 컷. ④ 임상 룰(배우자 작성) 1쪽 — 영유아·토들러 흉곽 압박 한계 그래프. pinch test가 카시트 안에 임베드된다. 매뉴얼·앱 불필요.
    2:00-4:00 실제 시연 (또는 사전 녹화): 마네킹 두 명 + 카시트 두 대. ① 마네킹 A(외투 없음): 하네스 적정 → LED 녹색. ② 마네킹 B(두꺼운 패딩): 채움 → LED 적색 + 진동 + "외투를 벗기세요" 음성. ③ 부모 페르소나 등장 → 외투 벗기고 재체결 → LED 녹색. ④ 운전 중 헐거워짐(시뮬레이션) → BLE 허브가 운전석 후방 미니 디스플레이에 알림. 부모의 인지 부담 0. 색만 보면 끝. 두꺼운 외투 슬립스루 자동 검출.
    4:00-5:00 차별 + 양산 + 팀: ① 차별 — Cybex/Evenflo SensorSafe(체스트 클립 BLE 점유)와의 비교 표 1쪽. ② 양산 — 1단계 애프터마켓 슬리브(다이치·페도라·브라이택스 호환) → 2단계 OEM 임베드 번들(현대차·기아 패밀리 SUV 신차 동봉). KC 인증은 1단계 슬리브로 가능. ③ 팀 — 본인 자율주행 다축 센서 퓨전 + 배우자 영유아 흉곽 임상 + 페르소나 두 아이 부모 검증 = 회사 안에서 우리만 만들 수 있다. 차별·양산·팀이 한 줄로 닫힌다.

    시연 실패 리스크 + Fallback 영상 계획¶

    • 실패 가능 부품:
    • BLE 허브 ↔ 4모듈 멀티플렉싱(현장 RF 간섭) → fallback: 1세트(어깨 ×2 + 클립 ×1)만 라이브, 4세트 통합은 사전 녹화 영상.
    • LED 응답 지연(현장 조명·온도 변화) → fallback: ≤200ms 응답을 사전 녹화 슬로우모션으로 검증 영상 보유.
    • 운전 중 알림(BLE 허브 → 디스플레이) → 현장 차량 미사용. 사전 녹화 영상으로 대체.
    • 사전 녹화 영상 5각도: ① 부모 시점(끈 당기기), ② 어깨 LED 클로즈업, ③ 마네킹 정면(외투 0겹/2겹), ④ 카시트 측면(하네스 전체), ⑤ 충전 도크 1초 부착(사용자 마찰 방어 컷).
    • 현장 PC 2대 + 무선 모니터: 시연 라이브 PC + fallback 영상 PC 분리. 라이브 실패 시 30초 내 전환.

    7. PoC 데이터 (예선 단계 산출 목표)¶

    본선 진출 전 서류·예선 3개월(2026-05-10 ~ 2026-08-10) 동안 만들어야 할 정량 데이터. 평가 4축 ① 실현 가능성(critic 16/25 약점) 점수 보강 핵심.

    • 데이터 1 — 외투 두께 vs 텐션 vs 픽스 위치 분리 가능성:
    • 측정: FSR + 변형게이지 합성 신호로 (외투 0/1/2겹) × (장력 헐거움/적정/과도) × (체결 위치 정상/오프셋) 27조합 × 9샘플 = 243건.
    • 목표: 외투 두께 2겹 슬립스루 위험 케이스를 F1 ≥0.85로 검출.
    • 데이터 2 — 임상 룰 안전 한계:
    • 측정: 배우자(간호사) 작성 영유아(8kg)·토들러(15kg) 단계별 흉곽 압박 한계 N치 + 적정 텐션 범위 ±15% 룰 문서.
    • 목표: 5쪽 임상 룰 가이드 + 알고리즘 매핑 표 (KC 인증 임상 시험은 사후 단계로 분리 명시).
    • 데이터 3 — 양산 경로 — OEM 인센티브 1쪽:
    • 카시트 OEM(다이치·페도라·브라이택스) 한국 본사 미팅 1회(이메일 시도 5건). 결과 1쪽 — "왜 OEM이 받을 인센티브가 무엇인가" critic 답.
    • 1단계 애프터마켓 슬리브 가격 시뮬레이션 1쪽 (BOM × 양산 단가 50% 할인 + 마진 30% = 부모 가격대).
    • 데이터 4 — 배터리 수명 시뮬레이션:
    • LED 5초 × 일 10회 + 딥슬립 30µA → 100mAh로 30일+ 측정 데이터 1쪽.

    이 4개 데이터가 "실현 가능성 16/25 → 21/25"로 끌어올리는 근거가 된다. 특히 데이터 1(F1 ≥0.85)은 critic의 "임상 데이터 확보 4개월 안에 불가" 공격에 대한 직접 답변 — 임상 시험이 아닌 물리 신호 분리 가능성 입증으로 우회.

    8. critic 방어 포인트 (정면 한 단락)¶

    "어깨 끈 임베드 인증·세탁성 + 카시트 1대 4모듈 사용자 마찰" — critic 의 16/25 핵심 공격 두 가지에 대한 plan 의 답은 다음 한 단락이다.

    양산은 두 단계로 분리한다. 1단계 애프터마켓 슬리브 형태(카시트 본체 무가공, 어깨 끈 위에 직물 슬리브로 부착)는 카시트 KC/FMVSS 인증 영향이 0이며 슬리브 자체 KC 전기·전자 인증만 받으면 즉시 출시 가능하다. 2단계 OEM 임베드 번들은 다이치·페도라·브라이택스와의 라이선싱 사업 모델로, 인증 책임을 OEM에 이전한다. 본선 데모는 1단계 슬리브 형태로 시연하므로 인증 우회 경로는 사실로 입증된다. 세탁성은 의료등급 실리콘 IPX7 포팅 + Pogo pin 자석 분리 충전으로 모듈 자체는 분리 후 슬리브만 가정 세탁기에 넣는다. M3 W11-12 게이트에서 세탁 5회 후 드리프트 ≤10% 정량 입증한다. 카시트 1대 4모듈(두 아이 8모듈) 마찰은 자석 4채널 충전 도크 1개로 부모 액션 1회/월로 압축한다 — 자동 페어링·30일+ 배터리·도크 부착 1초로 사용자가 보는 마찰점은 충전 도크 부착 한 번뿐이다. critic 의 "결국 부모는 안 쓴다"에 대한 답은 "부모가 봐야 할 것은 LED 색 하나, 부모가 해야 할 것은 도크 부착 한 번"이다.

    부록: 양산 경로 상세¶

    • 1단계 애프터마켓 (Year 1): 다이치·페도라 호환 어깨 패드 슬리브 형태. KC 전기·전자 인증만. 가격대 부모 직접 구매 8~12만원/세트(어깨 ×2 + 클립 ×1 + 충전 도크). 채널: 쿠팡·다이치 공식몰·산모교실.
    • 2단계 OEM 임베드 (Year 2~3): 다이치·페도라·브라이택스 신모델 카시트에 임베드 옵션 번들. 현대차·기아 패밀리 SUV(팰리세이드·카니발·EV9) 신차 구매 시 카시트 OEM 번들 패키지로 동봉. KC/FMVSS 인증은 OEM 책임.
    • 3단계 차량 OEM 통합 (Year 3+): BLE 허브가 운전석 후방 미니 디스플레이(#2 LullaMirror) 또는 양산 차량 클러스터로 알림 송출. 현대차·기아 패밀리 SUV 옵션 패키지.
    • 사내 모빌리티 서비스 시너지: 셔클·MoCean(현대차 모빌리티 자회사) 영유아 동승 차량에 사전 장착, 사용자 안전성 데이터 축적.
