    #1 SafeAlight Pod — 차량 외부 부착형 어린이 하차 안전 독립 박스¶

    • slug: safealight-pod
    • 캐치프레이즈: 차에 달지 못해도 차에 붙일 수 있다 — 카시트 점유부터 도어 핸들 LED까지, 차량 ECU 0의존 외부 부착 박스.
    • 주 테마 / 보조 테마: 1번 차량 혁신 / 4번 완전히 새로운 개념 (외부 액세서리화)
    • 수상 DNA: ② 기존 기술의 영리한 재해석(SEA를 양산 ECU 의존 없이 외부화) + ③ 사회적/포용적 가치(어린이 하차 사고 예방) + ④ 명확한 단일 페인포인트
    • 페르소나 페인: 주차 후 카시트 두 아이를 한 명씩 내리는 동안 옆을 지나는 자전거·전동킥보드·차량에 어린이가 무방비. 부모는 한 아이를 안느라 다른 아이를 못 본다. SEA가 없는 구형 차량/외산 차량을 모는 부모는 기능 자체가 없다.
    • 핵심 메커니즘:
    • 차량 후방 좌·우 휀더 또는 후미 범퍼에 강력 자석/3M 테이프로 부착되는 두 개의 외부 박스(좌·우).
    • 각 박스: 24GHz mmWave 레이더(접근 객체 거리·속도) + 광각 USB 카메라(객체 분류) + Jetson Orin Nano(AI 추론).
    • AI: YOLOv8 fine-tuning으로 자전거/전동킥보드/오토바이/보행자/차량 5분류 + TTC 산출.
    • 카시트 점유 패드(압력 매트, BLE)가 "어린이 탑승 차량"임을 박스에 알림 → 시동 OFF 후에도 N분간 박스만 저전력 액티브 유지.
    • 출력: 도어 핸들 외측에 부착된 LED 핸들 클립(자체 12V 배터리·BLE 연결)이 적·황·녹 점등. 위험 도어 핸들에 약한 진동 모터로 촉각 경고. 외부 접근자에게는 박스 자체의 LED 스트로보 + 작은 부저(70dB 이하) 패턴.
    • 부모 스마트폰 앱에 "오른쪽 위험: 자전거 4m, 왼쪽 도어 사용 권장" 한 줄 알림.
    • HW 제작 요소:
    • 외부 부착 박스 ×2 (3D 프린팅 IP65 케이싱, 자석 마운트, 8000mAh 리튬 배터리, 솔라셀 패널 옵션)
    • mmWave 레이더(Acconeer A121 또는 Texas Instruments IWR1443) ×2 + 광각 USB IR 카메라 ×2 + Jetson Orin Nano ×1(중앙 처리)
    • 도어 핸들 LED 클립 ×4 (RGB LED, 코인셀 + 진동 모터, BLE)
    • 카시트 압력 매트 ×2 (FSR 센서 어레이, ESP32, BLE)
    • 팀 강점 활용: 본인의 자율주행 객체 분류·TTC·센서 퓨전 코드 자산 그대로 재사용 + 배우자의 어린이 외상·하차 행동 패턴 임상 관점으로 알림 강도/timing 설계. 둘 다 살아남.
    • 차별 한 줄: SEA가 옵션인 양산차 한정인 반면, 이 박스는 어떤 차량에든 부착되어 ECU 없이 동일 기능을 제공한다 + 자전거/킥보드 비전 분류로 마이크로모빌리티 시대 정조준.
    • 이미 있을 가능성: 부분 존재. Hyundai/Kia SEA(양산), Honda Exit Warning, VW ID.7 등 OEM 양산 다수. 다만 모두 차량 내장형. 외부 부착 + 카시트 점유 연계 + AI 객체 분류 결합은 미발견. 애프터마켓 도어 LED(Botepon 등)는 단순 점등형으로 위험 분류 없음. 검증 출처: Hyundai SEA / Honda Exit Warning / Sphericalinsights Exit Warning Market. 차별축은 "OEM SEA의 애프터마켓 외부화 + 마이크로모빌리티 분류".
    • 4개월 데모 가능성: 가능.
    • M1 (1개월): 박스 케이싱 설계·3D 프린팅, 레이더+카메라 캘리브레이션, YOLOv8 자전거/킥보드 데이터 학습.
    • M2 (1개월): TTC/위험도 알고리즘, BLE 메시 통신(박스↔핸들 LED↔카시트 매트↔앱).
    • M3 (1개월): 통합·전력 최적화(저전력 모드 30분 유지), 도어 핸들 LED 클립 양산성 다듬기.
    • M4 (1개월): 주차장 시연 시나리오 영상화(자전거/킥보드 모형 접근), 야외 실측 데이터 수집.
    • 사용자 제작 역량 한계 위반 없음 — 차량 ECU 미사용, 모든 출력은 박스 자체 LED/부저/스마트폰.
    • 자가 약점: 외부 부착 박스의 도난·내후성·전력 지속성이 critic이 공격할 포인트. 양산 OEM의 SEA 대비 "왜 외부 박스인가" 답이 필요(애프터마켓·구형차/외산차 시장 + 카시트 점유 연계 차별). 도어 핸들 LED 클립의 양산 미관도 약점.

    #2 LullaMirror — 운전석 후방 미니 디스플레이 + 카시트 비전 AI 생체 모니터¶

    • slug: lullamirror
    • 캐치프레이즈: 룸미러 옆에 붙는 작은 거울. 그 거울이 두 아이의 호흡과 자세를 읽어 부모에게만 보여준다.
    • 주 테마 / 보조 테마: 1번 차량 혁신 / 3번 사업 연관 서비스 (헬스케어 데이터 수집 옵션)
    • 수상 DNA: ① 직관적 인터랙션(부모는 룸미러를 보던 시선 그대로) + ③ 사회적/포용적 가치(영유아 안전) + ④ 명확한 단일 페인포인트
    • 페르소나 페인: 카시트 두 아이가 뒷좌석에 잠들었을 때 부모는 운전 중 호흡/자세를 직접 확인할 수 없음. 룸미러로는 머리 떨굼/벨트 이탈도 식별 어려움. 시동 OFF 후 후석 방치 사고 예방.
    • 핵심 메커니즘:
    • 천장 또는 헤드레스트 후면에 거치되는 RGB+IR 듀얼 카메라 모듈(자석 마운트, 12V 시거잭 또는 자체 배터리).
    • 비전 AI: rPPG(POS/CHROM) 심박 + 흉부 ROI 광학 흐름 호흡수 + IR 체표면 온도 추정 + MMPose 키포인트로 머리 떨굼/벨트 이탈/카시트 자세 이상 감지.
    • 출력은 HVAC 폐루프가 아닌 두 가지 자체 디스플레이 HW로 재구성:
      • (a) 룸미러 옆에 클립으로 부착되는 2.4인치 운전석 후방 미니 디스플레이 — 두 카시트의 호흡 파형 + 안전 아이콘.
      • (b) 부모용 BLE 진동 손목 밴드 — 이상 패턴 시 진동 + 컬러 LED.
    • 시동 OFF + 후석 점유 감지 시 부모 스마트폰 앱 푸시("뒷좌석 어린이 탑승 중") + 차량 외부 거치형 LED 패널이 깜빡임으로 외부에 알림(주차 후 방치 사고 1차 차단).
    • 모든 처리는 Jetson에서 온디바이스. 영상은 저장하지 않음(프라이버시).
    • HW 제작 요소:
    • 천장 거치형 RGB+IR 듀얼 카메라 모듈 (3D 프린팅 케이싱, 광각 IR 카메라, 880nm IR LED 어레이, 자석 마운트)
    • Jetson Orin Nano + 5V/12V 통합 전원 보드
    • 룸미러 옆 클립형 2.4인치 디스플레이 (Waveshare 라운드 LCD + ESP32 + 클립 마운트)
    • BLE 진동 손목 밴드 (Adafruit nRF52 + 코인 진동 모터 + RGB LED + 3D 프린팅 밴드)
    • 외부 거치형 점멸 LED 패널 (윈도우 흡착 마운트 + LED 매트릭스 + 광 센서로 주야 자동 밝기)
    • 팀 강점 활용: 본인의 비전 AI 파이프라인(rPPG/키포인트/온디바이스 추론) × 배우자의 영유아 호흡·체온 정상범위 임상 기준·이상 패턴 트리거 설계. 임상 데이터 라벨링 가이드까지 배우자가 직접 작성 가능.
    • 차별 한 줄: 양산 후석 모니터는 "후방 카메라 영상을 그대로 보여주는" 수동형이지만, 이 거울은 생체 신호 추정 결과를 부모 시선이 닿는 위치에 한 줄 시각화한다 — HVAC 연동 없이도 폐루프(부모→대응)가 닫힌다.
    • 이미 있을 가능성: 부분 존재. BMW/Volvo의 후석 카메라, CPD(레이더 기반 어린이 탑승 감지), Bebcare/Babysense(가정용 호흡 매트), Nanit(가정용 카메라), Philips rPPG(라이선스 IP)는 양산 또는 가정용 시장. 자동차 카시트 ROI에 rPPG/호흡/자세를 결합 + 운전석 후방 미니 디스플레이 + 진동 손목 밴드 + 외부 LED 알림을 묶은 자체 동작 액세서리는 미발견. 검증 출처: Philips rPPG / Bebcare Mat / Nanit. market_researcher 정밀 조사 필요(특히 한국 출시 후석 모니터링 액세서리).
    • 4개월 데모 가능성: 가능.
    • M1: 카메라 모듈 + Jetson 통합, rPPG/MMPose 오픈소스 PoC.
    • M2: 영유아 마네킹 + 호흡 시뮬레이터로 데이터 수집 + 임상 정상범위 기반 트리거 설계.
    • M3: 디스플레이/손목 밴드/외부 LED 패널 통합, BLE 메시.
    • M4: 차량 1대 + 카시트 마네킹으로 통합 시연, 시동 OFF 방치 시나리오.
    • 사용자 제작 역량 한계 위반 없음 — HVAC 미연동, 모든 출력은 자체 HW.
    • 자가 약점: rPPG의 영유아 신뢰도(피부톤·움직임 노이즈)가 데이터로 입증되어야 함 → 임상 의료기기 수준이 아닌 "보조 알림" 포지셔닝 필수. 카메라 상시 촬영의 프라이버시 이슈 → 온디바이스 + 영상 무저장 강조. 운전 중 디스플레이 가시성이 산만함 유발 가능 → "이상 시에만 점등" UX 디자인.

    #3 SeatFit Coach — 카시트 설치 점검을 5초만에 끝내는 휴대형 비전 AI 도구¶

    • slug: seatfit-coach
    • 캐치프레이즈: 카시트의 46%가 잘못 설치되어 있다. 부모가 차에 가져가서 5초 비추면 끝나는 점검 박스.
    • 주 테마 / 보조 테마: 3번 사업 연관 서비스 / 1번 차량 혁신
    • 수상 DNA: ③ 사회적/포용적 가치(영유아 교통 안전) + ④ 명확한 단일 페인포인트(설치 오류 진단) + ⑤ 양산 경로 명시(카시트 OEM 동봉 액세서리·딜러 차량 구매 시 동봉·사내 모빌리티 서비스)
    • 페르소나 페인: NHTSA 통계상 카시트 46%가 잘못 설치됨. 부모는 등받이 각도(45°)·ISOFIX 잠금·하네스 하단 위치·체스트 클립 위치·하네스 장력(pinch test)을 다 외울 수 없다. 인증 기술자(CPST) 점검소는 예약 어렵고 한국엔 거의 없음. 두 아이라 매번 점검 필요(체격 성장 + 좌석 이동).
    • 핵심 메커니즘:
    • 부모가 휴대형 점검 박스(스마트폰 크기)를 카시트 옆에 5초 거치.
    • 박스 내부: ToF 거리 센서 어레이(등받이 각도 측정) + 광각 카메라(ISOFIX 잠금 인디케이터·하네스 위치·체스트 클립·라벨 인식) + IMU(차량 진동·기울기).
    • 비전 AI: ① 카시트 모델 라벨 OCR로 제조사·모델·만료일 자동 인식 → 클라우드 DB에서 해당 모델의 설치 가이드 매칭. ② ToF 어레이로 등받이 각도(영유아 45° / 토들러 30~45°) 정량 측정. ③ 카메라로 ISOFIX 인디케이터 색(녹/적) 인식 + 하네스 어깨 슬롯 위치(영유아: 어깨 아래 / 토들러: 어깨 위) + 체스트 클립 위치(겨드랑이 아래) 진단. ④ 부모가 박스를 하네스에 살짝 밀어 넣어 pinch test 정량화(2축 로드셀로 장력 측정).
    • 출력: 박스 상면 LED 매트릭스에 항목별 OK/경고 + 음성 가이드("등받이 각도 38도, 영유아 기준 45도. 베이스 뒤쪽을 1cm 들어주세요").
    • 클라우드 백엔드: 카시트 모델별 설치 가이드 + 만료일 + 리콜 정보 DB. 사업 연관 서비스로 확장 — 현대차·기아 차량 구매 시 동봉·인증 카시트 OEM과의 협업·딜러 차량 점검 시 같이 점검.
    • HW 제작 요소:
    • 휴대형 점검 박스 (3D 프린팅 케이싱, 손잡이형, 200g 미만)
    • ToF 거리 센서 어레이 (VL53L5CX 4×4 zone) — 등받이 각도/베이스 기울기
    • 광각 카메라 + 백색/IR LED 링 (저조도 보정) — 라벨 OCR 및 인디케이터 인식
    • IMU (BNO055) — 박스 자세 보정
    • 2축 로드셀 + 슬림 프로브 — pinch test 장력 정량화
    • LED 매트릭스(8×8) + 1W 소형 스피커 — 진단 결과 출력
    • Raspberry Pi 5 + 18650 배터리 + Wi-Fi/BLE
    • 팀 강점 활용: 본인의 비전 OCR·키포인트·센서 캘리브레이션·각도 추정 코드 자산 + 배우자(간호사)의 영유아 카시트 임상 가이드라인·CPST 매뉴얼·만료일 관리 노하우. 두 강점이 후보 중 가장 직접적으로 결합 — 배우자가 진단 알고리즘의 임상 룰베이스를 직접 작성 가능.
    • 차별 한 줄: CPST 화상 점검(Nuna Virtual)이나 점검소 방문 대신, 부모 손에 들리는 5초 자가 점검 도구 — 카시트 모델별 가이드 자동 매칭 + 정량 측정 + 임상 룰 적용.
    • 이미 있을 가능성: 미발견. CPST 인증 기술자 무료 점검(SafeKids·AAA·Nuna Virtual)은 인적 서비스. Cognex 등 산업용 비전은 카시트 제조 라인용. 부모용 휴대형 자가 점검 비전 AI 도구는 양산 사례 미발견. 검증 출처: NHTSA Car Seat Safety / Nuna Virtual Car Seat Check / SafeKids Right Fit. 차별축 매우 명확.
    • 4개월 데모 가능성: 가능.
    • M1: 박스 케이싱·전원·카메라·ToF·로드셀 통합 PoC.
    • M2: 카시트 5종 라벨 OCR 학습 + 등받이 각도/하네스 위치 룰 작성(배우자 협업).
    • M3: pinch test 로드셀 캘리브레이션 + 클라우드 DB 모델 매칭.
    • M4: 5종 카시트 + 인형 마네킹으로 30개 시나리오 시연 영상.
    • 사용자 제작 역량 한계 위반 없음 — 차량 ECU 미사용, 카시트 표면만 측정.
    • 자가 약점: 카시트 모델 데이터베이스 구축 비용(라벨 인식 데이터·설치 가이드 정리)이 큼. critic이 "왜 휴대형 박스인가, 스마트폰 앱이면 안 되나"를 공격할 것 — 답은 "ToF + 로드셀 + IR 링이 폰에 없다 + 정량 측정이 핵심" + Maker's Track HW 자격. 만료일/리콜 DB는 OEM 협업 없이는 한계.

    #4 PinchSense — 5점식 하네스 장력·위치를 실시간 LED로 코칭하는 카시트 임베디드 모듈¶

    • slug: pinchsense
    • 캐치프레이즈: pinch test를 외우지 마라. 카시트가 직접 빨갛게 켜져서 알려준다.
    • 주 테마 / 보조 테마: 4번 완전히 새로운 개념(카시트가 능동 진단 부품이 됨) / 1번 차량 혁신
    • 수상 DNA: ① 직관적 인터랙션(조작 0, 색만 보면 됨) + ③ 사회적/포용적 가치(영유아 안전) + ④ 명확한 단일 페인포인트
    • 페르소나 페인: 카시트 하네스 적정 장력은 "어깨에서 손가락이 미끄러지면 OK, 잡히면 NG(pinch test)" — 매번 반복 동작 + 두꺼운 외투 입은 겨울철 잘못 채움 사고 빈번. 부모가 한 명의 하네스를 채우는 동안 다른 아이는 떼를 쓰고, 결과적으로 "대충 채워서 출발"이 일상.
    • 핵심 메커니즘:
    • 카시트 5점식 하네스 어깨 끈에 임베디드되는 슬림 모듈 ×2(좌/우 어깨 끈).
    • 각 모듈: 정전식 압력 센서(어깨와 끈 사이 압력) + 인장 센서(끈 자체 장력, FSR + 변형 게이지) + 6축 IMU(끈 각도) + RGB LED 스트립(끈 외측, 1cm 폭) + 진동 모터.
    • 체스트 클립에는 별도 ToF 센서 모듈 — 클립의 수직 위치(겨드랑이 높이 ±2cm)를 카시트 등받이 기준으로 측정.
    • 알고리즘: 어깨 압력 + 끈 장력 + IMU 각도를 결합한 "하네스 적합도 점수"(0~100). 체스트 클립 위치는 별도 OK/NG.
    • 출력: 끈 자체 LED가 적색(헐거움) → 황색(중간) → 녹색(적정)으로 실시간 변화. 부모는 끈을 당기면서 LED가 녹색이 될 때까지만 당기면 끝(별도 매뉴얼·앱 불필요). 체스트 클립 위치 NG 시 클립 모듈 진동 + 빨간 LED. 출발 후에도 헐거워지면 BLE로 운전석 후방 미니 디스플레이(또는 #2 LullaMirror 연동)에 알림.
    • 카시트 OEM과의 양산 경로: 인증 카시트 제조사(다이치·페도라·브라이택스 등) 협업, 또는 OEM 동봉 액세서리(현대차·기아 신차 구매 시 카시트 OEM 번들).
    • HW 제작 요소:
    • 하네스 어깨 모듈 ×2 (정전식 압력 센서 패치, FSR + 변형 게이지, BNO055 IMU, RGB LED 스트립 1cm×8cm, 코인 진동 모터, ESP32-C3, LiPo 100mAh)
    • 체스트 클립 모듈 (VL53L1X ToF, RGB LED, 진동 모터, 코인셀 배터리, 자석 충전)
    • 카시트 베이스 BLE 허브 (ESP32 + 18650 + 자석 마운트)
    • 5점식 카시트 목업(시연용, 시중 카시트 1개 + 임베드 가공)
    • 팀 강점 활용: 본인의 다축 센서 퓨전(IMU/압력/장력 동시 처리) + 임베디드 SW + 알고리즘 캘리브레이션 + 배우자(간호사)의 영유아 흉곽 압박 안전 한계·체스트 클립 임상 가이드·겨울 외투 시나리오 라벨링. 두 강점 모두 살아남.
    • 차별 한 줄: 5 Point Plus(패시브 anti-escape 패드) 같은 기존 액세서리는 "이탈 방지"만, PinchSense는 체결 정확도를 능동 측정해 LED로 실시간 가이드 — pinch test가 카시트 안에 임베드된 형태.
    • 이미 있을 가능성: 미발견. 카시트 점유 감지(CPD)·시트벨트 텐션 사전인장기(Tesla 등)는 양산이지만 모두 차량 측 + 충돌 직전용. 5 Point Plus·Chicco MyFit 등은 패시브 카시트 액세서리. 5점식 하네스 장력·위치 실시간 LED 코칭 모듈은 미발견. 검증 출처: 5 Point Plus / Chicco Pinch Test Guide / Tesla Vision Seatbelt / Cognex Seatbelt Inspection. market_researcher 정밀 조사 필요(특히 한·중·일 영유아 액세서리 시장).
    • 4개월 데모 가능성: 가능하나 #1~#3 대비 도전적.
    • M1: 어깨 모듈 PCB 설계·압력/장력 센서 캘리브레이션·LED 스트립 임베드 패키징.
    • M2: 임상 룰 작성(배우자, 영유아·토들러 단계별 적정 장력 범위) + IMU 각도 보정.
    • M3: 체스트 클립 ToF 모듈 + BLE 허브 통합.
    • M4: 카시트 1대에 임베드 + 마네킹 시연 + 두꺼운 외투 시나리오 영상.
    • 사용자 제작 역량 한계 위반 없음 — 차량 ECU 미사용, 카시트 자체 모듈.
    • 자가 약점: 어깨 끈에 전자부품을 임베드하는 안전성·세탁성·인증(KC/CCC/FMVSS)이 critic 핵심 공격. 답은 "데모용 액세서리 형태로 시연 + 양산은 카시트 OEM 협업" 명확 분리. 배터리 수명/자석 충전 UX도 약점. 5점식 하네스 직물 속에 슬림 모듈 임베드는 메이커 환경에서 시연 수준만 가능.
