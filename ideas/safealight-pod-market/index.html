    시장 조사 — SafeAlight Pod (외부 부착형 어린이 하차 안전 박스)¶

    slug: safealight-pod 작성일: 2026-05-10 작성자: market_researcher 대상 batch: reports/ideas/2026-05-10-batch2.md

    종합 판정¶

    지표 값
    양산품 동일도 50%
    시장 니즈 강도 70% (강)
    추천 액션 GO
    한 줄 결론 OEM SEA는 모두 차량 내장형이며 외부 부착형 + 마이크로모빌리티 비전 분류 + 카시트 점유 연계 결합은 미발견. 차별축 명확.

    OEM 양산 매트릭스¶

    OEM 모델·연식 공식 명칭 동일/유사 메커니즘 동일도 출처
    Hyundai/Kia 다수 (Palisade/Tucson/Telluride 등) Safe Exit Assist (SEA) / Rear Occupant Alert (ROA) 후방 BSD 레이더로 차량 접근 감지 시 후석 도어 잠금 보조 60% (차량 내장 한정) Hyundai Owner Manual SEA / Hyundai SmartSense
    Audi A4 (2016~), A8 Exit Warning 레이더로 자전거 감지, 사이드미러·도어 트림 LED 점멸, 도어 잠금 60% Dutch Reach Project
    Ford EU 모델 (Edge 등) Exit Warning 자전거 접근 감지, 사이드미러 적색 LED + 음성 경고 55% Ford Media
    Volkswagen ID.7 Exit Warning 시동 OFF 후 3분간 자전거 감지 시 도어 차단 55% Electrek
    Honda (글로벌) Exit Warning EW 후방 접근 차량 검출, 도어 알림 50% BikeBiz

    핵심 갭: 모든 OEM 양산품은 ① 차량 내장(애프터마켓 외부 부착 X), ② 마이크로모빌리티(전동킥보드) 분류 명시 X, ③ 카시트 점유 연계 활성화 X.

    경쟁사/스타트업/애프터마켓¶

    • JVIS Illuminated Door Handles — 단순 점등형 LED 도어 핸들, 위험 분류·경고 기능 없음 — 동일도 15% — JVIS
    • Primo Dynamic Door Handle LEDs — 차량별 LED 도어 핸들 액세서리, 단순 미관용 — 동일도 10% — Primo Dynamic
    • Garmin Varia / Wahoo TRACKR Radar — 자전거용 후방 레이더 + 라이트(자전거→차량 인지 방향 반대) — 동일도 20% (메커니즘 유사, 사용 시나리오 정반대) — Wahoo TRACKR
    • Carmanah Vehicle Detection — 인프라형 차량 감지 비콘 (도로 인프라용, 차량 부착 X) — 동일도 5% — Carmanah
    • 종합: 차량 외부 부착형 + 레이더+카메라 통합 + AI 객체 분류 + BLE 도어 핸들 LED + 카시트 매트 연계 통합 제품은 미발견.

    한국 사용자 니즈 증거¶

    • 노랗IT월드 "택시 개문사고 과실비율" — "정차 차량 옆을 지날 때는 항상 '문이 열릴 수 있다'고 생각하고 지나가는 것이 좋습니다" / "전기자전거와 전동킥보드는 엔진음이 없어 사이드미러 확인 없이 문을 열면 바로 사고로 이어질 수 있습니다" — 보험·법률 핫이슈 — 노랗IT월드
    • 나무위키 "문콕" — 한국 운전자 일상 키워드, 도어 사고 사회적 문제로 정착 — 나무위키
    • 한국일보 "전동킥보드 사고 무면허 논란 확산" — 2025년 11월 기사, 규제 강화·이용자 감소 사회적 의제 — 한국일보
    • easylaw 개문사고 법령 — "차 문을 연 쪽 과실이 크게 잡히는 경우 많음" — 부모가 도어 사고 시 100% 가까운 과실 부담 — 찾기쉬운 생활법령정보
    • 종합: 페인포인트 강도 강. 마이크로모빌리티(전동킥보드/전기자전거) 급증 + 어린이 하차 시점이 부모 시야 사각 + 과실 책임이 차량 측에 집중되는 구조 → 부모의 직접적 회피 도구 수요가 양산 OEM 옵션에만 묶여 있는 한계 명확.

    차별 가능 각도¶

    1. 애프터마켓 외부화 — 양산 OEM SEA는 신차 옵션 또는 상위 트림 한정. 외부 부착형이면 구형/외산/저가 차량까지 시장 확장. 한국엔 SEA 미장착 차량이 다수.
    2. 마이크로모빌리티 비전 분류 — 양산 OEM SEA는 대부분 후방 차량(BSD 레이더 기반)에 최적화. 전동킥보드·자전거를 명시적으로 분류하고 TTC를 산출하는 박스는 마이크로모빌리티 시대 대응으로 차별 명확.
    3. 카시트 점유 연계 + 도어별 차등 알림 — 카시트 압력 매트 BLE로 "어린이 탑승 차량"임을 박스에 신호 → 시동 OFF 후에도 N분 액티브 + 도어 핸들 LED 적·황·녹 차등 표시. OEM SEA는 일반적인 후석 도어 잠금/경고에 머무름.
