## #1 BabyVision Guardian — 카시트 비전 AI 생체 모니터 + HVAC 연동
- **slug**: `babyvision-guardian`
- **캐치프레이즈**: 뒷좌석 카시트 두 아이의 호흡·체온·자세를 비전 AI로 읽고, 차량 공조가 스스로 반응한다.
- **주 테마 / 보조 테마**: 1번 차량 혁신 / 3번 사업 연관 서비스 (헬스케어 데이터)
- **수상 DNA**: ① 직관적 인터랙션(부모가 조작 안 해도 차가 인지) + ③ 사회적/포용적 가치(영유아 안전) + ④ 명확한 단일 페인포인트
- **페르소나 페인**: 카시트 두 아이가 뒷좌석에서 잠들었을 때, 운전 중 부모가 룸미러로 호흡/체온을 직접 확인할 수 없음. 차내 온도 편차로 한 아이는 땀, 다른 아이는 추위. 최악의 경우 차내 방치 사고.
- **핵심 메커니즘**:
  1. 천장 RGB+IR 카메라 1대로 두 카시트 동시 모니터링.
  2. 비전 AI: rPPG(원격 광용적맥파)로 심박 추정, 흉부 ROI 광학 흐름으로 호흡수 추정, IR로 체표면 온도 추정.
  3. 자세 추정(키포인트 모델)으로 머리 떨굼/카시트 벨트 이탈 감지.
  4. 추정값을 차량 HVAC ECU에 전달 → 좌/우 카시트 영역별 풍량·온도 자동 조절.
  5. 시동 OFF 후 후석 점유 감지 시 부모 앱 푸시 + 비상시 비상등/창문 자동 제어.
- **팀 강점 활용**: 비전 AI 모델 설계·온디바이스 추론 최적화 + 센서 퓨전(본인) × 영유아 호흡/체온 정상범위·이상 징후 임상 기준·카시트 안전 가이드라인(배우자). 둘이 동시에 살아나는 결합.
- **차별 한 줄**: 단순 "후방 카메라 보기"가 아니라 생체 신호 추정 → 차량 공조와 ECU 레벨에서 폐루프 제어로 연결.
- **이미 있을 가능성**: 부분 존재. 후석 카메라 모니터링(BMW, Volvo)·CPD(Child Presence Detection, 레이더 기반)는 양산 중. 그러나 rPPG/호흡수 + HVAC 폐루프 + 두 카시트 개별 제어를 결합한 사례는 확인 안 됨 → market_researcher 정밀 조사 필요.
- **4개월 데모 가능성**: 가능. rPPG 오픈소스(POS, CHROM 알고리즘) + 자세 추정(MediaPipe/MMPose) 활용으로 모델 학습 부담 낮음. 데모는 실제 차량 1대 + 카시트 마네킹/유아 시뮬레이터로 구성. HVAC 연동은 CAN 시뮬레이터 또는 시연용 12V 팬 제어로 축소판 시연 가능.
- **자가 약점**: rPPG가 영유아의 약한 흉부 움직임에서 안정적으로 동작하는지 데이터 입증 필요. 안전 기능을 표방하면 의료기기·법규 리스크 질문이 올 수 있어 "보조 알림"으로 포지셔닝해야 함. 카메라 상시 촬영의 프라이버시 이슈 → 온디바이스 처리 강조 필수.

## #2 SafeAlight — 외부 인지 센서 재해석으로 막는 어린이 하차 사고
- **slug**: `safe-alight`
- **캐치프레이즈**: 차에 이미 달린 BSD·서라운드뷰 카메라를 어린이 하차 순간으로 다시 겨눈다 — 추가 부품 없이.
- **주 테마 / 보조 테마**: 4번 완전히 새로운 개념(기존 ADAS 자산의 용도 전환) / 1번 차량 혁신
- **수상 DNA**: ② 기존 기술의 영리한 재해석(2025 트레일러 토잉형 — 추가 BOM 0에 가까움) + ③ 사회적/포용적 가치(어린이 교통사고 예방) + ④ 명확한 단일 페인포인트
- **페르소나 페인**: 주차 후 두 아이를 카시트에서 내리는 동안, 옆을 지나가는 자전거·전동킥보드·차량에 어린이가 무방비 노출. 부모는 한 아이를 안느라 다른 아이를 못 본다. "도어 존" 사각이 가장 위험.
- **핵심 메커니즘**:
  1. 시동 OFF 후에도 BSD 레이더 + 서라운드뷰 카메라 + 코너 라이다(있을 시)를 저전력 모드로 N분간 활성 유지.
  2. 비전: 접근하는 자전거/킥보드/보행자/차량을 분류 + TTC(Time To Collision) 산출.
  3. 좌/우 도어별 위험도 평가 → 도어 핸들 LED 적색 점멸 + 도어 잠금 소프트 홀드(어린이가 도어 핸들 당겨도 0.5초 지연 후 해제) + 외부 조명/혼 패턴으로 접근자 경고.
  4. 부모 스마트폰에 "오른쪽 위험, 왼쪽 도어 사용 권장" 한 줄 알림.
  5. 카시트 점유 감지(시트 압력)와 결합 → 어린이 탑승 차량에서만 활성, 오작동 최소화.
- **팀 강점 활용**: ADAS 인지 스택(객체 분류·트래킹·TTC, 본인) + 어린이 외상 사례·하차 행동 패턴 임상 관점(배우자). 자율주행 도메인 자산을 "주차 중" 시간대로 전환하는 발상.
- **차별 한 줄**: 주행용 ADAS를 "정차·하차 5분"의 사각지대로 돌려 쓰는, 추가 부품 0의 SW-only 기능.
- **이미 있을 가능성**: 부분 존재. 현대차 SEA(Safe Exit Assist)는 후석 도어 잠금 보조 기능으로 양산 중. 다만 ① 카메라+레이더 퓨전으로 자전거/킥보드까지 분류, ② 도어별 위험 차등 알림, ③ 도어 핸들 LED + 외부 경고음/라이트 패턴, ④ 카시트 연계 활성화는 확인 안 됨. 차별축은 "SEA의 다음 세대 — 마이크로모빌리티 시대 대응".
- **4개월 데모 가능성**: 가능. 사내 차량의 BSD/AVM 센서 데이터 접근이 핵심 변수 — R&D본부 자산 활용 가능성 높음. 객체 검출은 사전학습 모델 활용, TTC 로직은 본인의 자율주행 코드 자산 재사용. 데모는 주차장에서 자전거/스쿠터 모형이 접근하는 시나리오로 영상화 가능.
- **자가 약점**: 사내 SEA 팀이 이미 유사 로드맵을 가지고 있을 가능성 높음 → "사내 IP 충돌"을 critic이 지적할 것. 차별축을 "마이크로모빌리티 분류 + 도어별 차등 + 카시트 연계"의 3중 결합으로 명확히 좁힐 것. 시동 OFF 후 ADAS 가용 시간(배터리 영향) 정량화 필요.
