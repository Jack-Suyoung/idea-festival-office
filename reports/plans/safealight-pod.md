## 1. 한 줄 요약
- **4개월 동안 만들 것**: 차량 후방 휀더 자석 부착형 외부 박스 ×2(레이더+카메라+Jetson) + 도어 핸들 LED 클립 ×4 + 카시트 압력 매트 ×2 + 부모 앱이 BLE 메시로 통합되어 자전거/킥보드 접근 시 적·황·녹 LED + 외부 부저 + 폰 알림을 트리거하는 자체 동작 시제품 1세트.
- **핵심 데모 메시지**: "당신의 차에 SEA가 없어도, 외산 차량이어도, 1분 만에 자석으로 붙이면 카시트 두 아이를 안고 내릴 때 자전거·킥보드를 부모 대신 본다."

## 4. HW/SW 분담

- **가용 시간**: 본업 외 평일 저녁 12시간 + 주말 6시간 = **주 18시간** × 16주 = **약 288시간**
- **HW 작업: 35%** (약 100시간) — 박스 케이싱 SLA 3D 프린팅·IP65 가스켓 본드 결합·자석 마운트 설계·도어 핸들 LED 클립 PCB 발주/조립·카시트 매트 FSR 어레이 본드·도난 와이어/솔라셀 통합·실차 부착 지그
- **SW 작업: 45%** (약 130시간) — YOLOv8 fine-tuning(자전거/킥보드/보행자 한국 도심 데이터)·TTC 알고리즘·BLE 메시 4노드 프로토콜·저전력 듀티 사이클·카시트 점유 연계 룰·부모 앱(Flutter or React Native 단일 화면)
- **데모 준비: 20%** (약 58시간) — 야외 주차장 시연 영상 5종 촬영·편집·fallback 영상·5분 슬라이드·리허설 3회

- **4개월 가능성**: **타이트하지만 가능**.
  - 위험 시점: **M2 W6-7의 BLE 메시 4노드 통신**과 **M3 W10-11의 false positive 튜닝**. 본업 야근/가족 일정 충돌 시 1주 이상 슬립 가능성.
  - **축소판 fallback (위험 시 우선 축소 항목)**:
    1. 솔라셀 보조 패널 → 슬라이드에 도해만 (BOM #9 제외)
    2. 도어 핸들 LED 4개 → 2개(우측 전·후만)로 축소
    3. 카시트 매트 2개 → 1개로 축소(한 명 시나리오)
    4. 박스 ×2 → 박스 ×1(우측만, 한국 도심 도어 사고 우측 인도 측 다수)
  - 위 4개를 다 축소해도 **핵심 데모 메시지(자전거 접근 → 도어 핸들 LED 적색 + 외부 부저)는 보존됨**.

## 7. PoC 데이터 (예선 단계 산출 목표)

본선 진출 전 **서류·예선 3개월 동안** 만들어야 할 정량 데이터(실현 가능성 점수 근거):

- **데이터 1 — 객체 분류 정확도**: 한국 도심 주차장 야간/우중 자체 수집 영상 30분 + 공개 데이터셋 보강으로 **YOLOv8n 자전거/전동킥보드/보행자 3분류 mAP@0.5 ≥ 0.70** 검증 리포트 (slide 1장).
- **데이터 2 — 자석 마운트 내구성**: 휀더 도장면 100회 탈착 + 80km/h 풍동 모사(또는 차량 주행 30분) 후 박스 위치 변위 ≤ 5mm.
- **데이터 3 — 시동 OFF 저전력 가동 시간**: 8000mAh 배터리 + 듀티 사이클 10% 조건에서 **최소 30분 액티브 모드 유지** 측정 로그(전류계 데이터).
- **데이터 4 — 외부 부저 데시벨**: 1m 거리에서 70dB 이하 측정(소음계 사진 + 도로교통법 경음기 110dB 한도 대비 비교 차트).
- **데이터 5 — BLE 메시 지연**: 박스↔도어 핸들 LED↔카시트 매트↔폰 4노드 end-to-end 지연 ≤ 300ms (1분간 1000회 측정 평균).
- **데이터 6 — False Positive 율**: 정상 보행자 + 지나가는 차량 + 빈 박스 100시나리오에서 위험 알림 오발생 ≤ 5%.

이 6개 데이터가 **"실현 가능성 19/25 → 22/25" 보강의 핵심 근거**가 되며, evaluator·critic의 "PoC 데이터로 입증 안 됨" 감점 사유 직접 해소.

### 2단계 — OEM 옵션 / 신차 동봉 (12~24개월)

- **현대차·기아 SEA 표준화 추세**와 정합: 표준 SEA가 후방 차량만 본다면, SafeAlight Pod는 자전거·전동킥보드·보행자를 추가 분류하는 "SEA Plus" 포지션.
- **카시트 OEM 협업**: 다이치·페도라·브라이택스와 카시트 매트 동봉 번들 → 어린이 탑승 차량 한정 자동 활성화 시나리오.

### 3단계 — 모빌리티 서비스 (24개월~)
- 현대차·기아 카셰어링·렌터카 차량에 박스 ×2 표준 부착 → 카시트 동승 가족 단위 고객의 안전 차별화.

## 9. critic 방어 포인트 (한 단락)

> **외부 부착 UX (도난·미관·내후성)**: 자석 마운트는 휀더 내측에 위치하여 외부 시인성이 낮고, 강철 와이어 도난 방지 + IP65 가스켓 케이싱 + 솔라셀 보조 + "주차 시 분리 / 도어 핸들 LED는 영구 부착" 2단계 운용 시나리오로 미관·도난·전력을 동시에 회피한다. 양산 시에는 차량 색상 매칭 옵션과 휀더 통합 마운트(접착식)로 마감 품질을 OEM 수준으로 끌어올린다.
>
> **OEM SEA 카니발리제이션**: 현대차·기아 사내 양산과의 충돌은 "신차 SEA 대체"가 아니라 "**SEA 미장착 구형/외산/저가 차량 retrofit + 마이크로모빌리티 분류 추가 가치**" 두 축으로 회피한다. 1단계 애프터마켓은 SEA 0대 차량을 시장으로 잡고, 2단계 OEM 옵션은 표준 SEA 위에 자전거·킥보드 분류와 카시트 점유 연계를 더하는 "SEA Plus"로 포지션한다. 카니발리제이션은 발생하지 않으며 오히려 SEA 양산 라인의 옵션 매출을 늘린다.
