# 아이디어 페스티벌 2026 출품 후보

> 현대차·기아 사내 아이디어 페스티벌 **Maker's Track** 출품을 위한 멀티에이전트 파이프라인 산출물 모음.

## 이 사이트는

6개의 Claude Code subagent(`idea_generator`, `market_researcher`, `evaluator`, `plan_designer`, `critic`, `reporter`)로 구성된 사무실 파이프라인이 **발산 → 시장 검증 → 1차 평가 → 4개월 계획 → 2차 평가 → 비판 → 최종 보고**의 7단계를 거쳐 만든 출품 후보 자료를 담고 있습니다.

## 평가 루브릭

대회 공식 4축 (각 25점) + 보조 축으로 구성:

```
공식 4축
  1. 실현 가능성 (PoC 데이터 + 양산 경로)
  2. 독창성 (한 문장 차별화)
  3. 기술 적합성 (회사 기술 자산 시너지)
  4. 고객 지향성 (페르소나 + 페인포인트)

보조 축 (탈락 트리거)
  ✗ 시중/경쟁사 출시품 (market_researcher 검증)
  ✗ 사용자 제작 역량 초과
  ✗ 4대 테마 미적합
```

## 팀 구성

- **본인** — 자율주행 SW (비전 AI / ADAS 인지 스택 / 센서 퓨전)
- **배우자** — 간호사 (영유아 임상·안전 가이드 / 카시트 안전 룰)
- **페르소나** — 카시트 두 아이를 키우는 부모

## 컨텍스트

- **대회 주최**: 현대차·기아 R&D본부 + AVP본부
- **사이클**: 서류 선정 약 3개월 → 본선 6팀 → 실물 제작 약 4개월
- **2024 수상**: ADSM(시선 사이드미러, 대상), H-브리즈(수소차 가습), 스마트 러기지
- **2025 수상**: ANT(옴니 트랜스포터, 대상), 트레일러 토잉, 디지로그 락

## 사이드바 메뉴

좌측 사이드바의 단계별 산출물:

- **최종 보고서** — 사내 예선 제출용 1페이지 패키지
- **아이디어 발산** — `idea_generator` 산출물 (batch1, batch2, 피드백)
- **시장 조사** — `market_researcher` 산출물 (OEM 양산 / 경쟁 제품 / 사용자 니즈)
- **4개월 로드맵** — `plan_designer` 산출물 (16주 마일스톤 / BOM / 리스크)
- **정량 평가** — `evaluator` 산출물 (1차 + 2차 plan 반영 재평가)
- **Critic (5축 공격)** — `critic` 산출물 (Devil's Advocate)
