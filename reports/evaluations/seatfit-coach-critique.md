## 공격 5개

### A. 기술 허점 — 비전/ToF/OCR 일반화 결함
**공격**:
플랜은 "카시트 5종(다이치·페도라·브라이택스·맥시코시·사이벡스)으로 한국 점유율 80% 커버"라고 주장하지만 본선 심사위원이 양산 경험자라면 다음 3개를 동시에 묻는다. ① **OCR 정확도 ≥90%(테스트 50장)는 학습 카시트의 신품 라벨에서만 측정한 것이고**, 실차에서는 라벨이 검게 그을렸거나 카시트 천에 의해 일부 가려지는 **out-of-distribution** 케이스가 50% 이상이다. 양산용 ADAS OCR도 동일 데이터셋에서 95%여도 도로 위에서 80% 미만으로 떨어지는 사례가 흔하다. ② **ToF VL53L5CX의 ±2° 캘리브레이션은 "단단한 평면" 기준 사양**이다. 카시트 등받이는 폴리에스터/네오프렌 천 + 스폰지 패딩으로 덮여 있어 940nm IR이 산란되어 거리 표준편차가 사양보다 2~3배 커진다([ST VL53L5CX datasheet 권장 동작 조건은 "low-reflectance soft target" 별도 캘리브레이션 필요](https://www.st.com/resource/en/datasheet/vl53l5cx.pdf)). 검은색 카시트(영유아 카시트의 60% 이상)에서는 **반사율 5% 이하**라 ranging error가 대폭 증가한다. plan W2~W4 게이트 "각도 측정 ±2°"는 어떤 카시트로 측정한 결과인가? **단 1종(다이치) 단단한 패널부에서만 측정했을 가능성이 매우 높다**. ③ **OCR 신뢰도 임계값 설정 근거 부재** — plan은 "신뢰도 임계값 + 매뉴얼 폴백"이라고만 적었지 임계값 0.7인지 0.9인지, false positive 시 잘못된 임상 룰 매칭으로 **부모에게 잘못된 안전 가이드가 출력되는 리스크**(예: 토들러용을 영유아용으로 매칭 → 등받이 각도 30° 권고 부모가 45°로 들어올림 → 충돌 시 머리 떨굼)는 어떻게 막는가? 이는 의료기기는 아니지만 **안전 도구 위양성(false safe)** 책임 문제다.

**답변/개선**:
- ① OCR OOD: plan W9 "5종 카시트 회귀 테스트" + W6 "정확도 ≥85%(30장)" 정도로는 부족. **각 카시트 모델 × 라벨 경년열화(신품/3개월 사용/2년 사용) × 조명(주광/형광/IR 링 전용) × 가림(천 25%/50%) 매트릭스 30장 이상**을 PoC 데이터셋으로 추가 → 보강 1주(W9에 흡수). 답변 가능.
- ② ToF 천 산란: **카시트 모델별 천 보정 계수표** 작성. 5종 카시트의 등받이 정중앙 패널부에서 ground truth 각도(±0.5° 디지털 각도계) 대비 ToF raw 값으로 회귀 계수 도출. plan W7~W8에 4h 추가. 검은색 카시트 시연 1종 반드시 포함. 답변 가능.
- ③ 위양성 책임: **"진단 결과 출력 시 항상 카시트 모델명 음성 confirm 후 진행"** UX 강제 (예: "다이치 미라클 모델로 인식했습니다. 맞나요? 1번 시작 / 2번 다른 모델 선택"). 신뢰도 ≥0.9 미만이면 자동 매뉴얼 폴백. 임상 룰베이스 매칭 실패 시 **ToF 각도/로드셀 장력만 출력하고 임상 가이드 음성은 silence**. 답변 가능.

**판정**: ⚠️ 답변 부족 — 답변 자체는 가능하나, 현재 plan PoC 데이터(데이터 1·2·3) 정의가 신품·실내·단일조명 기준이라 본선 직전에 OOD 약점이 노출될 가능성이 크다. **plan_designer 환류 필수**.

### B. 차별화 부족 — 폰+BLE+OEM 자체 인디케이터 3개 동시 공격
**공격**:
plan은 BOM #21에 시중 BLE 텐션 게이지 1개를 사서 **사이드바이사이드 비교 영상**을 만들겠다고 하지만, 본선 심사위원의 진짜 공격은 그 영상으로 **막히지 않는다**.
- **공격 B-1 (Britax ClickTight 양산 인디케이터)**: 다이치/페도라가 아닌 **Britax ClickTight 시리즈**는 이미 **카시트 측면에 색상 코드 레벨 인디케이터 + Lockoff 시각 표시**가 양산 중이며 [Carseat.org 2025 Britax Grow With You ClickTight Review](https://www.car-seat.org/threads/2025-britax-grow-with-you-clicktight-combination-car-seat-review-the-next-frontier-update-from-our-blog.230886/) 와 [Consumer Reports Britax Boulevard ClickTight Review](https://www.consumerreports.org/babies-kids/car-seats/britax-boulevard-clicktight/m372932/) 에서 "**리클라인 인디케이터·텐션 락오프가 Editor's Pick 수준**"으로 평가 받음. 카시트 자체에 이미 인디케이터가 있는데 **부모가 추가로 80만~228만원 도구를 들 이유**가 무엇인가? "다 모델 커버"라는 답은 약하다 — Britax ClickTight 사용자는 자기 카시트의 인디케이터만 보면 된다.
- **공격 B-2 (Cybex SensorSafe + Evenflo 폰 앱)**: market에서 인용한 [Cybex SensorSafe](https://www.cybex-online.com/en/us/sensorsafe-safety-kit_us.html) 와 [Evenflo SensorSafe](https://www.evenflo.com/pages/sensorsafe) 는 **체스트 클립 BLE + 폰 앱 + 카시트 모델별 설치 영상**까지 양산 중. 폰 앱 + 인-카시트 BLE 클립이 합쳐지면 plan이 자랑하는 "ToF·로드셀·IR 링이 폰에 없다"는 답이 약해진다 — **장력은 BLE 클립이 측정**하면 되고, **모델별 가이드 영상은 폰이 보여주면** 된다.
- **공격 B-3 (구매 트리거)**: 부모가 **Britax 사용자가 아닌 다이치 사용자**라면 다이치 [순정 인디케이터](https://www.bambibaby.com/blogs/learning-center/nuna-lumn-vs-britax-grow-with-you-clicktight-harness-2-booster-car-seat-car-seat-comparison) 에 의존한다. SeatFit Coach 한 줄 차별축 "5초 거치 자가 점검"이 **부모의 일회성 점검 용도라면 80만원 도구를 사기엔 비싸고**, 매일 점검 용도라면 부모가 **box를 차에 두고 배터리 관리**할 의향이 있는지 데이터가 없다. plan은 SUS만 측정하지 **구매 의향(WTP)은 측정 안 함** (plan L127 자가 인정).

**답변/개선**:
- B-1 (Britax 인디케이터): "Britax ClickTight는 자체 카시트 한정 + 정성 인디케이터(녹/적 LED 단순 표시)이고, **인증 카시트 점검소(CPST)가 한국에 거의 없어** 부모가 자기 인디케이터를 어떻게 해석할지 모른다 — 다이치/페도라/맥시코시 등 한국 점유율 80%는 인디케이터 자체가 없거나 피지컬 라벨뿐"이라는 답을 plan §6 데모 시나리오 1:30~2:00에 **"5종 카시트 순정 인디케이터 부재 비교 표"** 1슬라이드 추가로 강화 가능. 답변 가능.
- B-2 (Cybex/Evenflo 폰+BLE): plan BOM #21이 외장 BLE 1개만 사는데 — **Cybex SensorSafe Kit 또는 Evenflo SensorSafe 1세트를 추가 구입(약 10만원)해 시연 영상에 포함**. "체스트 클립 BLE는 체결 여부만, 등받이 각도/하네스 슬롯/만료일 OCR은 못 함" 4축 비교를 정량 매트릭스로 굳히기. plan_designer 환류로 BOM 1건 추가. 답변 가능.
- B-3 (구매 트리거): **plan §7 PoC 데이터에 "데이터 7: 부모 SUS 5명 대상 WTP 인터뷰(자비 0~30만원 / OEM 동봉 0~신차 옵션 인센티브) 정성 인용 5건"** 추가 — W12에 SUS와 함께 30분 인터뷰. 80만원 자비 구매 가설 자체를 버리고 **"신차 동봉 / 보건복지부 사업"이 양산 메인**임을 더 명확히. 답변 가능.

**판정**: ⚠️ 답변 부족 — 3개 공격 모두 보강 1~2주로 메울 수 있으나 **plan_designer 환류 3건(슬라이드/BOM/WTP 인터뷰) 동시 필요**. 답변 자체는 구조적 결함이 아니라 "준비 부족".

### C. 양산성 의문 — 카시트 모델 DB 100+ 확장 + OEM 채널 협상
**공격**:
이 후보의 가장 큰 양산 결함이고 evaluation 2차에서도 critic 집중 약점으로 지목된 항목이다.
- **공격 C-1 (DB 갱신 비용)**: 한국 카시트 시장은 다이치([newstomato.com 다이치 시장 점유율 47% 1위, 누적 판매 80만대](https://www.newstomato.com/ReadNews.aspx?no=874566))를 필두로 **연간 신모델 5~10종 출시 + 단종 3~5종**이 반복된다. plan은 "5종 PoC → 한국 점유율 80% 커버"라고 주장하지만, 다이치만 해도 미라클·플러스·이지핏·세이프존 등 **단일 OEM 내 활성 라인업이 4~6종**이다. 총 활성 모델 50~80종. 이걸 **누가 라벨링하고 만료일/리콜 정보 갱신하는가**? plan은 "OEM 협업"이라 말하지만 다이치/페도라가 **자기 신차 OEM이 아닌 SeatFit Coach팀에게 모델 가이드/리콜 데이터를 무상으로 푸시할 인센티브가 0**이다. 오히려 다이치는 자기 [홈플러스 PB 채널](https://www.ebn.co.kr/news/articleView.html?idxno=1445450) 까지 만들어 **자체 앱/가이드 영상으로 사용자를 가두는 것**이 비즈니스 우위다. 외부 진단 도구는 다이치 입장에서 "리콜 데이터 노출 리스크"이지 협업 인센티브가 아니다.
- **공격 C-2 (현대차·기아 신차 동봉 채널의 현실)**: plan은 "Palisade·Carnival·Sorento·Telluride 패밀리 SUV 신차 동봉"을 양산 2단계로 명시했는데, 현대차·기아의 **H-Genuine Accessory 채널 등록 절차는 통상 24~36개월 + 충돌·EMC·KC 인증** 필요. 16주 PoC가 아무리 잘 되도 **양산 시점은 2028~2030년**이고 그 사이 카시트 OEM은 자기 SensorSafe류로 진화한다. 심사위원의 핵심 질문: "**왜 현대차·기아가 다른 OEM 카시트 점검 도구를 자기 신차에 동봉하는가? 그게 무슨 마케팅 차별화?**" plan은 "패밀리 SUV 안전 마케팅 + 영유아 가족 NPS"라고 답했지만 — **NPS 상승의 정량 데이터 0**, 동봉 비용(228만원/대 BOM은 PoC 단가, 양산 단가는 5~10만원으로 떨어져야 함, 수율·인증 포함) 산정 0.
- **공격 C-3 (Maker's Track 한계)**: 외부 박스 200g + RPi5 + 18650 ×2 + 3D 프린팅 PETG는 **Maker's Track 데모는 가능하나 양산 가능 형태가 아니다**. RPi5(1.3만원 BOM)는 산업용 등급 아니고, ESP32-S3·로드셀 HX711 모두 시연 부품이다. 양산은 ASIC/MCU 통합 + 사출 케이스 + 카시트 OEM 인증이 필요한데 그 거리감이 5분 발표에서 "사내 R&D본부가 즉시 채택"이라는 그림으로 안 그려진다.

**답변/개선**:
- C-1 (DB): **"OEM 협업 안 되어도 50종 라벨링은 1인 ×2주(외부 알바)로 가능"** — 다이치 4종 + 페도라 3종 + 브라이택스 3종 + 맥시코시 3종 + 사이벡스 3종 + 그라코 2종 + 조이 2종 = **20종으로 한국 점유율 90% 커버 가능** (시장 long-tail은 매뉴얼 폴백). 만료일/리콜은 **공공 데이터(국토부·KC 인증센터·CPSC 리콜 DB) 크롤링**으로 OEM 무관하게 갱신 가능. plan_designer 환류로 "DB 자체 갱신 파이프라인" 1슬라이드 추가. **답변 가능 (단 OEM 협업 의존도가 plan보다 더 약하다는 솔직한 그림으로 재포지셔닝)**.
- C-2 (신차 동봉): **양산 채널을 "신차 동봉"에서 "보건복지부·서울시 영유아 안전 지원 사업 우선"으로 재정렬**. 현대차·기아 동봉은 3단계 장기로 미루고 1단계 = 정부 사업, 2단계 = H-Genuine Accessory 액세서리, 3단계 = 신차 옵션. plan §6 4:00~5:00 슬롯의 양산 로드맵 슬라이드 재구성. **답변 가능**.
- C-3 (Maker's Track 양산 거리): **"본선 발표용 박스는 PoC, 양산은 카시트 OEM SDK 라이선스 형태"** 명시 — 즉 SeatFit Coach 팀은 휴대형 박스를 양산하지 않고, **임상 룰베이스 + 모델 매칭 알고리즘 + ToF 캘리브레이션 노하우를 IP로** 제공하고 카시트 OEM이 자기 SensorSafe류 차세대에 임베드. 이러면 H-Genuine Accessory 동봉은 "**SeatFit IP가 들어간 카시트 자체**"가 된다. **답변 가능 (단 idea_generator 환류로 차별 한 줄 재정비 필요 — "휴대형 박스" → "다 모델 카시트 진단 IP 플랫폼"**).

**판정**: ⚠️ 답변 부족 — 3개 공격 모두 답변 가능하나 **양산 그림이 plan에서 "신차 동봉"으로 너무 앞서 있어 본선 심사위원에게 비현실적으로 비칠 위험**. 재포지셔닝 1주 + 슬라이드 1장 추가로 메울 수 있음.

### D. 페인포인트 약함 — NHTSA 미국 통계 + 한국 인용의 약점
**공격**:
- **공격 D-1**: plan과 market이 일관되게 인용하는 **NHTSA 46% 통계는 미국 시장**이다. 한국에서 "잘못 설치" 통계가 **카시트 자체 미사용** 통계와 섞여 인용되는 경우가 많고, 본선 심사위원이 한국 도로교통공단/행안부 정량 데이터를 직접 묻으면 — market.md L37~44 인용 7건은 **모두 매체 가이드 콘텐츠 또는 부모 자발 후기**이지 정부 정량 통계가 아니다. "한국 부모의 50%가 카시트를 잘못 설치한다"는 정량 출처가 plan에 없다.
- **공격 D-2 (구매 트리거 vs 걱정)**: market.md 인용 [econmingle 롱패딩 기사](https://econmingle.com/car/i-made-my-kids-wear-long-padded-coat/) 와 [클리앙 카시트 잘 태우기](https://www.clien.net/service/board/lecture/18121244) 는 **부모의 "걱정"을 보여주지 "228만원짜리(혹은 양산가 30만원)도구 구매 의향"을 입증하지 않는다**. 미국 NHTSA 무료 CPST 점검도 **참여율은 15% 미만**으로 알려져 있고(인적 서비스조차 이용률 낮음), 한국에서는 점검소 자체가 거의 없으니 부모가 **"점검의 필요성을 느끼고 있다"는 가정 자체가 약하다** — 부모는 "카시트는 사면 다 비슷하게 채우는 거 아니냐"가 디폴트일 수 있다.
- **공격 D-3 (한국 기후/도로 특수성)**: 한국 부모의 진짜 카시트 페인 1순위는 **여름 차량 내부 50°C 카시트 온도 + 겨울 롱패딩**이다. econmingle 인용은 롱패딩 페인을 명시하는데, plan의 SeatFit Coach는 **"롱패딩 입은 상태로 점검"하면 OK로 잘못 진단할 수 있다** (장력은 외투 압축 후 측정되므로 충돌 시 외투 압축 분만큼 헐거워짐 — 이걸 박스가 어떻게 감지하는가?).

**답변/개선**:
- D-1 (정부 통계): **도로교통공단 어린이 카시트 사용 실태 조사(연 1회 발간)** + **한국교통안전공단 카시트 자체 충돌 시험 데이터**를 plan §7 발표 페인 영상에 인용 추가. market_researcher 추가 조사 1회. 답변 가능.
- D-2 (구매 트리거): **plan §7 데이터 7로 "지인 부모 5명 WTP 인터뷰" 추가** (B 공격과 중복으로 통합). 본선에서는 **"자비 구매 시장이 아니라 정부·OEM 동봉 시장"이라는 솔직한 포지셔닝**으로 답하기. 답변 가능.
- D-3 (롱패딩): **"롱패딩 모드" 임상 룰을 룰베이스에 추가** — 박스가 카메라로 외투 두께를 추정(영상 분류) → 외투 두께 ≥3cm 감지 시 "외투를 벗기고 다시 채워주세요" 음성 가이드. 배우자 임상 자문 시간(80h 중 5h)으로 추가 가능. **차별 한 줄에도 "롱패딩 자동 감지"를 넣어 한국 시장 차별화 강화**. 답변 가능 + idea_generator 환류로 차별 한 줄 보강.

**판정**: ✅ 답변 가능 — D-1·D-2는 보강, D-3은 오히려 차별 강화 기회. 본선 심사위원이 "한국 부모 페인" 묻는다면 롱패딩 자동 감지 한 슬라이드가 강력한 답.

### E. 발표/시연 약점 — 5분 임팩트 + fallback 신뢰성
**공격**:
- **공격 E-1 (5분 임팩트)**: plan §6 데모 시나리오는 페인(0:30) → 메커니즘(1:00) → "왜 폰 아닌가"(0:30) → 라이브 시연(1:30) → 차별·양산·팀(1:00) 으로 5분에 6개 메시지를 우겨넣었다. 본선 심사위원 50명+R&D본부장은 "**한 줄 차별축**"이 5분 후 머리에 남아야 하는데 — plan의 한 줄("휴대형 + 다모델 + 정량 + 임상")은 **수식어 4개**다. SafeAlight Pod의 "OEM SEA의 외부화 + 마이크로모빌리티 분류"는 한 줄로 즉시 이해되는데, SeatFit Coach 한 줄은 "다 모델"이 무슨 차별인지 카시트를 모르는 R&D본부장이 즉시 이해 못 함.
- **공격 E-2 (라이브 시연 부품 의존성)**: plan §6 라이브 시연(2:00~3:30, 1.5분)은 **OCR + ToF 각도 + LED 매트릭스 + 음성 TTS 4개가 모두 동시에 작동**해야 한다. 발표장 조명은 형광등(IR 링과 충돌), Wi-Fi off(클라우드 매칭 fallback 정적 JSON 동작 검증 필요), 음향(1W 스피커가 발표장에서 들리는가?). 4개 중 1개라도 실패하면 fallback 영상 전환인데 — **fallback 영상은 라이브의 1/3 임팩트밖에 안 된다**(심사위원이 "왜 라이브 안 하지?" 의심). 부품 9개 BOM 중 단 1개라도 발표 직전 고장 시 백업 박스 1세트만으로 충분한가? RPi5 SD카드 손상이면 백업 박스도 같은 risk.
- **공격 E-3 (도해 한 장으로 메커니즘 전달)**: plan §6 0:30~1:30에 "메커니즘 슬라이드 1장 + 박스 분해도 1장"이라고만 적혀 있는데, **R&D본부장 1분 안에 "왜 5초 안에 4개를 동시에 보는지"가 한 그림으로 이해되어야 한다**. ToF 4×4 zone + 광각 카메라 + 로드셀 프로브 + IMU + LED 매트릭스 5개 부품을 한 분해도에 그리면 복잡도 폭발. 도해 1장이 부족할 위험.

**답변/개선**:
- E-1 (한 줄): **"부모 손에 들리는 카시트 점검소"** 한 줄로 재정비. "다 모델·정량·임상"은 부제 1줄. 한국에 CPST 점검소가 거의 없다는 페인이 즉시 답이 됨. idea_generator 환류로 차별 한 줄 재작성. 답변 가능.
- E-2 (라이브 의존성): **부품을 묶어 "측정 1단계(ToF+IMU 각도) → 결과 LED만"** 으로 라이브 시연을 좁히고, OCR + 임상 가이드 음성은 **사전 녹화 영상으로 전환**. 라이브는 1분 내 단순 시연(거치→3초→LED 색 바뀜) + 영상 1.5분 보충 + 비교(폰+BLE) 1슬라이드. plan_designer 환류로 §6 시간 재배분 + 라이브 부품 축소. 답변 가능.
- E-3 (도해): **"5초 + 4가지" 1픽토그램(스톱워치 + 4개 체크리스트 아이콘)** 한 그림 + 박스 사진 1장으로 분해도 대체. 분해도는 부록 슬라이드. plan_designer 환류로 슬라이드 디자인 1건. 답변 가능.

**판정**: ⚠️ 답변 부족 — 3개 모두 보강 가능하나 **plan §6 데모 시나리오 자체가 라이브 의존도 너무 높음**. plan_designer 환류로 시연 순서·분량 재설계 1주 필요.
